## Trust Boundaries

| Boundary | Description |
| --- | --- |
| session memory slot metadata -> active_slots | Inherited slots may enter working state only after registry freshness/scope/thread/intent checks. |
| LLM slot extraction -> resolved slots | Current-turn extraction is a candidate/current-turn input, not a required-slot policy source. |
| legacy router -> target router projection | Target router naming must not change finite legacy edge keys used by LangGraph compilation. |
