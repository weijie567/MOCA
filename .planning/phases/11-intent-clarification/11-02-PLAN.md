<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user text -> deterministic pre-router | Untrusted text may impersonate approval commands or high-risk action requests. |
| policy helper -> graph router | Pure helpers must not perform side effects or trust runtime manifest data. |
| deferred intent admission -> runtime taxonomy | GAD-02 admission rules prevent silent default enablement of new intents. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Spoofing / Elevation of Privilege | `detect_pre_route` | mitigate | Approval-looking text maps to `approval_chat_not_trusted` and cannot output `approval_decision`, `approval_result`, or resume. |
| T-11-02 | Tampering | `PreRouteDecision` | mitigate | Use Pydantic `BaseModel` with `extra="forbid"` and Literal-constrained dispositions/operations. |
| T-11-03 | Tampering / Information Disclosure | required-slot table | transfer | `REQUIRED_SLOT_POLICY` is defined here; Plan 11-03 evaluates completeness and blocks missing slots. |
| T-11-04 | Elevation of Privilege | confidence gate helper | mitigate | `confidence_requires_clarification` prevents low-confidence/high-risk requests from read-only routing and forbids confidence-only action authorization. |
| T-11-05 | Repudiation | coverage metadata | transfer | Critical classes are declared here; Plan 11-05 enforces per-class manifest/golden coverage and stale hash failure. |
</threat_model>
