## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| classifier state -> graph route | Untrusted model-derived intent fields choose only deterministic route keys. |
| slot extraction -> investigation/tools | Missing required slots must stop before read tools or action paths. |
| candidate slot hints -> completeness | Candidate hints are model output and cannot become trusted slots. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-03 | Tampering / Information Disclosure | `route_after_slots` | mitigate | Deterministic `missing_required_slots` blocks missing slot groups before `investigate`; candidate slots are ignored for completeness. |
| T-11-04 | Elevation of Privilege | confidence route | mitigate | Low confidence and high-risk operation ambiguity route to clarification/risk-safe paths; no confidence-only action route exists. |
| T-11-05 | Repudiation | route coverage claims | transfer | Plan 11-05 verifies manifest/golden route coverage and stale metadata failure. |
