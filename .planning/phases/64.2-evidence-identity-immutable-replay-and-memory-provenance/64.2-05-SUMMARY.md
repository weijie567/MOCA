## Decisions Made

- Authority class is evaluated before transport status: `contextual_only` always observes and `unknown` always rejects, even if a caller attaches successful transport and typed refs.
- Policy promotion accepts only a complete canonical identity with exact serialized `scope_type="tenant_policy"` and `scope_id=str(tenant_id)`; merchant/request scope is never invented.
- CWC continues using its existing `evidence_refs_json` physical column for non-authoritative observation storage to avoid an undeclared schema migration. Runtime/hydration exposes only `CaseWorkingContextObservationV1`; this compatibility name does not make observations evidence.
- Exact source-set dedupe sorts complete canonical identities before comparison, so ref ordering cannot create duplicate facts while distinct sources remain independent.
