## Sampling Rate

- **After every task commit:** Run that task's focused `uv run pytest` command and scoped `uv run ruff check`.
- **After every plan wave:** Run the union of focused suites for all completed plans in the wave.
- **Before `$gsd-verify-work`:** Full Phase 64.2 aggregate and repository-wide suite must be green.
- **Max feedback latency:** 120 seconds for task-level feedback; longer PostgreSQL/full-suite gates are wave-level.
