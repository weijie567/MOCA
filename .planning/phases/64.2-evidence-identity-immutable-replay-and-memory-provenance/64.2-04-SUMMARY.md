## Decisions Made

- Approval validation fixes evidence scope to exact `scope_type="tenant_policy"` and `scope_id=str(tenant_id)`; merchant/request scope is not accepted as a substitute.
- Empty verified input derives from repository output for compatibility. Any non-empty verified list in create, edited action, proposed action, or info payload must exactly equal the canonical projection.
- A replacement action may override the old action's evidence through an explicit top-level evidence payload, but independently supplied replacement action evidence must agree with it.
- Edit results carry replacement verified evidence into re-risk while the superseded request retains its historical snapshot/binding.
