## Decisions Made

- Existing public hash primitives retain the legacy default so compatibility callers cannot silently reinterpret stored hashes; all new typed builders explicitly select v2.
- Stored long-term/case rows infer legacy versus v2 only when their content/source/candidate hashes match that profile exactly; otherwise identity verification fails closed.
- Complete source refs are preserved exactly. A run-based discriminator is synthesized only for candidates that supplied no durable discriminator.
