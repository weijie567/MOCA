## Decisions Made

- Empty/no-evidence writes pass an empty typed list, while raw/reduced dicts are rejected before any event, snapshot, or dependency row is added.
- Snapshot JSON records capture-time immutable identity, lifecycle, hash, locator, compatibility provenance, and retention. Replay adds retained content and current lifecycle at read time without altering stored capture data.
- Current lifecycle uses immutable version rows and lineage only; mutable `PolicyDocument`/`PolicyChunk` heads are never substituted for historical truth.
- Legacy compatibility is explicitly event-bound and read-only. Missing or ambiguous aliases stay unresolved and return no verified retained content.
- `archived` was added only to the existing immutable-evidence checks and tests; no archive service, endpoint, or unrelated schema was introduced.
