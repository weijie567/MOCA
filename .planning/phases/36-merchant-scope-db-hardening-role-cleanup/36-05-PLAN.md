<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| legacy database rows -> hardened schema | Unsafe historical data must be blocked or fail-closed before constraints land. |
| migration backfill -> AgentRun scope | Backfill can create future authorization facts and therefore must use only authoritative proof. |
| downgrade -> legacy data | Rollback must not silently destroy legacy business records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T36-01 | Elevation of Privilege | user preflight/check constraint | mitigate | Reject active merchant-bound users without tenant-consistent merchant binding before constraint creation. |
| T36-02 | Spoofing | username migration | mitigate | Preflight same-tenant duplicates and create `uq_users_tenant_username` only after ambiguity checks. |
| T36-03 | Tampering | AgentRun backfill | mitigate | Forbid weak-source tokens in migration source and classify ambiguous legacy rows as `unknown_legacy`. |
| T36-05 | Tampering / Repudiation | approval/action/snapshot consistency preflight | mitigate | Block target merchant contradictions linked to business-scoped runs. |
| T36-06 | Information Disclosure | policy-only/unknown legacy runs | mitigate | Check constraints prevent null target business runs; unknown legacy remains fail-closed. |
</threat_model>
