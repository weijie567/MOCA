<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent final state -> terminal memory write | Final graph state may contain approval markers; only completed terminal finalization may sanitize those markers before session memory write. |
| Terminal finalizer -> AgentStep table | Retry or duplicate stream calls can otherwise append duplicate `agent_run_memory_finalize` trace rows. |
| Agent run requester identity -> memory/CWC writes | Terminal memory surfaces must bind to the original run requester, not an approval reviewer. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-59-01-01 | Elevation of privilege | `src/agent/nodes/memory_write.py` approval skip boundary | mitigate | Keep `_approval_or_interrupted(...)` unchanged; strip approval markers only in `agent_run_memory` terminal-finalizer service state. |
| T-59-01-02 | Tampering | `AgentStep` finalizer trace persistence | mitigate | Query existing `AgentStep` with `node_name == FINALIZER_NODE` before appending finalizer trace steps. |
| T-59-01-03 | Spoofing | requester identity helper | mitigate | Build finalizer input state from persisted `AgentRun.user_id` and fetched requester `User`, not reviewer/admin graph resume actor. |
| T-59-01-04 | Repudiation | finalizer persistence rollback path | mitigate | Preserve rollback-and-suppress trace append behavior so assistant-message/thread-summary commits remain durable and retry-safe. |
</threat_model>
