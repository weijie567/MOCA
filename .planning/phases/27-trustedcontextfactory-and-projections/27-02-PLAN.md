<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API/auth/run inputs -> TrustedContextFactory | Authenticated User, verified token scopes, and server-created ids become canonical authority. |
| TrustedContext -> service projections | Projection-local metadata may be added, but identity/scope fields cannot be overridden. |
| TrustedContext -> AgentState identity | Only canonical identity fields are projected; permissions and merchant_scope remain service-context-only. |
| Existing intent constants -> registry APIs | Registries expose read-only catalog data and must not become mutable policy state. |
