## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client/user payload -> API route | Untrusted request body/query fields must not define tenant, user, role, permissions, merchant_scope, thread, run, trace, or locale authority. |
| LLM/graph output -> platform context | Model output and checkpointed AgentState are untrusted for permissions and merchant scope. |
| API/auth/run boundary -> TrustedContextFactory | Authenticated User, verified token scopes, server ids, and server-derived merchant scope become the only canonical trusted source. |
| TrustedContext -> service projections | Projection-local metadata may be added, but identity/scope fields must be copied from canonical context only. |
| Knowledge request filters -> KnowledgeService | User/model merchant filters must be authorized against trusted merchant_scope before retrieval. |
| Approval/replay metadata -> approval/replay services | Context projections may carry refs/versions, but must not create approval truth or event truth. |
