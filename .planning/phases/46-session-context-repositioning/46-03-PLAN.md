| Boundary | Description |
|----------|-------------|
| session prompt hints -> verifier / recommendation / approval paths | Session hints enter prompt context but must not satisfy authority checks. |
| memory_write side effect -> durable memory layers | Ordinary completed runs may write session context, but must not auto-create long-term preference or reviewed case-memory records. |
| session/reviewed memory -> CWC lifecycle | CWC identity must come from trusted case refs, not session or reviewed memory. |
| test results -> validation artifact | `46-VALIDATION.md` must not claim compliance until approved-entrypoint commands pass. |
