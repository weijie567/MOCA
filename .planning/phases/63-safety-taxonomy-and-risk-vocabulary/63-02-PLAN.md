| Boundary | Description |
|----------|-------------|
| LLM risk output -> backend risk policy | LLM `RiskAssessment` is advisory and is normalized before routing/action decisions. |
| risk_gate -> approval/action path | Risk gate creates proposed actions, hashes, snapshots, risk decisions, and approval/auto-allowed bindings. |
| legacy persisted/API risk_level -> runtime semantics | Existing strings remain readable but no longer define new routing semantics. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-63-06 | Elevation of Privilege | `risk_assessment.risk_level` | mitigate | Emit severity-only `risk_level` plus explicit `risk_disposition`; tests forbid manual_review/blocked as new severity. |
