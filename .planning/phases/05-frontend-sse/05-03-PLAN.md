创建 frontend/src/hooks/useAgentRun.ts：

Hook 管理完整的 run 生命周期：
- submitQuery(query) → createRun → connectToRunEvents
- 收集 SSE events 到 steps[] 数组
- 跟踪 runStatus: idle | running | completed | waiting_approval | rejected | degraded | failed | disconnected
- approval_required 事件时设置 approvalId
- final_response 事件时设置 finalResponse
- SSE 断连时设置 disconnected，调用 getRunStatus 恢复
- approveRun / rejectRun 方法调用 decideApproval 后轮询 getRunStatus（2s 间隔）

State shape:
```typescript
interface AgentRunState {
  runId: string | null
  status: RunStatus | 'idle'
  steps: SseEvent[]
  finalResponse: string | null
  approvalId: string | null
  error: string | null
}
```

Export: useAgentRun() → { state, submitQuery, approveRun, rejectRun, reset }
