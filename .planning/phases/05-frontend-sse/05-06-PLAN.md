- In `apiFetch`, wrap `fetch` in `try/catch`.
- Parse response body with `await response.json().catch(() => null)`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> FastAPI REST/SSE | Untrusted UI actions and bearer tokens cross into protected run and approval APIs. |
| Demo role switcher -> auth endpoint | User-selected demo role maps to seeded usernames and requests JWTs. |
| Approval UI -> approval API | Manager/admin actions can resume or reject high-risk agent execution. |
| Vite dev server -> API container | `/api` proxy target is controlled by `VITE_API_URL` in Docker compose. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-06-01 | S/E | Demo auth/RBAC | mitigate | Map roles only to seeded users `cs_zhang`, `mgr_li`, `admin_user`; disable protected submit until real JWT fetch succeeds. |
| T-05-06-02 | I/S | Token handling | mitigate | Remove all `demo-token:*` placeholder bearer tokens; only `access_token` from `/auth/demo-token` is installed with `setAuthToken`. |
| T-05-06-03 | T/D | SSE duplicate execution | transfer | Backend mitigation is in Plan 05-05; frontend still treats 409/non-2xx as visible `ApiResult` failure instead of retry-looping silently. |
| T-05-06-04 | I/E | Tenant isolation | mitigate | Pending approvals are loaded only through `GET /api/v1/approvals` with backend tenant filtering and bearer JWT; frontend does not accept tenant IDs from user input. |
| T-05-06-05 | E/R | Approval authorization | mitigate | Approve/reject acts on selected pending approval IDs returned by the authorized API; self-approval/insufficient-role errors are surfaced from normalized API failures. |
| T-05-06-06 | I | Docker/API routing exposure | mitigate | Vite proxy reads `process.env.VITE_API_URL` so compose uses `http://api:8000`; browser clients keep relative `/api/v1` paths and do not expose internal service names. |
</threat_model>
