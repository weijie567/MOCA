Update `frontend/src/lib/api.ts`:

- Replace `ApiResult<T>` with a discriminated shape:
  `type ApiResult<T> = { success: true; data: T; error?: undefined } | { success: false; data: null; error: { code: string; message: string } }`.
- In `apiFetch`, wrap `fetch` in `try/catch`.
- Parse response body with `await response.json().catch(() => null)`.
- If `!response.ok`, return `{ success: false, data: null, error: body?.error ?? { code: `HTTP_${response.status}`, message: response.statusText || 'Request failed' } }`.
- If the body is missing, non-JSON, or `body.success !== true`, return `{ success: false, data: null, error: body?.error ?? { code: 'INVALID_RESPONSE', message: 'Invalid API response' } }`.
- On thrown network/proxy errors, return `{ success: false, data: null, error: { code: 'NETWORK_ERROR', message: error instanceof Error ? error.message : 'Network error' } }`.
- Export `ApprovalRecord` with the fields from `ApprovalResponse`, and add:
  `export async function getPendingApprovals() { return apiFetch<{ approvals: ApprovalRecord[]; total: number }>('/approvals') }`.

Update `frontend/src/hooks/useAgentRun.ts`:

- Wrap `createRun`, `recoverRunStatus`, each polling `getRunStatus`, and `decideApproval` in `try/catch` even though `apiFetch` normally normalizes failures.
- On create/recovery/evidence/trace/approval exceptions use visible messages:
  create: `'执行遇到问题，请重试。如问题持续，请联系管理员'`;
  recovery: `'连接中断，状态恢复失败'`;
  approval: `'审批提交失败'`.
- Preserve current behavior for expected SSE close after `final_response` or `approval_required`.

Update `frontend/src/components/details/ApprovalTab.tsx`:

- Import `getPendingApprovals`, `decideApproval`, and `ApprovalRecord`.
- Fetch pending approvals on mount and after every successful direct decision. Store `pendingApprovals`, `selectedApprovalId`, and `loadError`.
- Render a pending approvals list above the action details. Each pending item must show `risk_level`, `risk_rule_ref`, `created_at`, and `run_id`, and selecting it sets `selectedApprovalId`.
- Compute `activeApproval` from `selectedApprovalId`; prefer the SSE `approvalId` record if no pending list record is selected.
- `confirmDecision()` must call `decideApproval(activeApproval.id, pendingDecision, reason)` for selected pending records. If `activeApproval.id === approvalId` and `onApprove`/`onReject` is provided, call those handlers so current-run polling is preserved.
- Disable approve/reject when no `activeApproval` exists or `activeApproval.status !== 'pending'`.

Update `EvidenceTab.tsx` and `TraceTab.tsx`:

- Add `.catch((error) => ...)` or `try/catch` inside the effect loader so rejected helper promises set `error` instead of leaving stale loading/empty state.
