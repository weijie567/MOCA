# Phase 24.2 Plan: Unified Session Memory Bundle Read Path

## Objective

Make `SessionMemoryBundle` the graph-facing session read model for rolling summary, recent messages, tool summaries, and slot continuity while preserving the existing `session_memory` slot-continuity contract.

## Tasks

1. Add a shared agent-context adapter that loads or validates a `SessionMemoryBundle` from graph state/config and projects it into the existing `ContextAssembler` input shape.
2. Update `session_memory_load` to attach `session_memory_bundle` when enough trusted config exists, while still returning `session_memory` from `bundle.slot_continuity`.
3. Update `extract_slots`, `generate_recommendation`, and `assess_risk_and_approval` to use the shared bundle adapter instead of direct duplicated `ConversationService.load_prompt_context(...)` calls.
4. Add regressions proving:
   - `session_memory_load` returns both `session_memory` and `session_memory_bundle`.
   - prompt nodes consume an existing bundle without directly calling `ConversationService.load_prompt_context(...)`.
   - prompt context remains prompt-safe and preserves prior rolling summary/recent/tool summary behavior.

## Non-Goals

- No schema migration.
- No change to memory write path.
- No change to authority boundary semantics.
