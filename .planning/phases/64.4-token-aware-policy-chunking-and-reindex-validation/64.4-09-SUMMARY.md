## Accomplishments

- Implemented the fixed 14-gate `rag_token_chunk_ab.v1` profile using only integer counts, `Fraction` and versioned `Decimal` cost values; rounded decimals exist only in Markdown display.
- Added strict safe terminal schemas and atomic create-only JSON/Markdown pairs for `selected_pass`, `candidate_failed` (`quality_fail` or `safety_fail`), `unavailable` and `execution_error`; only `selected_pass` can create the independent selection decision/hash.

- Reused the production ingestion/COW/retrieval runtime while containing all internal commits under a connection-owned rollback transaction; resource proofs preserve chunk, duplicate, offline/provider token and config observations before evaluation cleanup.
- Retained Plan10 ownership: no deterministic fake was presented as live evidence, no `selected_pass` artifact was fabricated, and no pointer, activation history or receipt was mutated.

## Decisions Made

- Kept the exact fixed profile unchanged: Hit@5, spread, Hit@1/3/MRR, per-format Hit@5, anchor/locator/fallback, duplicate, chunk and token gates compare raw rational values only.
- Used one embedder/provider/retrieval configuration for both roles while limiting the incumbent to `CharacterCompatibilityAssembler` and the candidate to `PolicyEmbeddingInputAssembler`.
- Treated provider token totals as `unavailable` whenever every durable ingestion observation cannot prove provider-reported usage; no aggregate usage is invented or allocated.
- Used hard-link create semantics from fully fsynced temporary files for create-only JSON/Markdown pairs and deterministic JSON-to-Markdown projections; conflicts preserve existing bytes.
- Bound a passing selection to the real complete inactive candidate identity and parity/report hashes, but deliberately kept activation/pointer/history/receipt fields out of both schemas.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Contained production commits below the true transaction owner**

- **Found during:** Task 2 submission self-review after the first green gate.
- **Issue:** An `AsyncSession.begin()` root could be ended by `IngestionService.ingest_document()` calling `session.commit()`, so the initial finally rollback could not prove zero committed COW pointer/history changes.
- **Fix:** Moved the rollback owner to an exclusive `AsyncConnection` transaction and bound the evaluator session with `join_transaction_mode="create_savepoint"`; production commits now release only savepoints and the connection transaction always rolls back.
- **Files modified:** `src/rag/evaluation/retrieval_rounds.py`, `tests/eval/test_rag_retrieval_round_isolation.py`.
- **Verification:** The regression simulates an internal commit and asserts create-savepoint configuration, session close and outer rollback; final scoped gate is `118 passed`.
- **Committed in:** `c605bfff`.

**2. [Rule 3 - Blocking compatibility] Preserved Phase64.3 resume/test seams while adding resource proofs**

- **Found during:** Task 2 first GREEN gate.
- **Issue:** Existing resume repository spies and simplified projection fixtures lacked the new resource method/fields, causing 10 scoped failures before contract behavior could be checked.
- **Fix:** Added safe zero/unavailable compatibility defaults and a fallback to the established resume proof API; real runtime still requires nonzero resources before a completed A-B observation can select.
- **Files modified:** `src/rag/evaluation/retrieval_rounds.py`, `src/repositories/rag_evaluation_round_repo.py`, `tests/eval/test_rag_retrieval_round_isolation.py`.
- **Verification:** First gate `105 passed, 10 failed`; after correction and added acceptance coverage, final gate `118 passed`.
- **Committed in:** `c605bfff`.

**3. [Rule 1 - Test bug] Scoped the no-activation assertion to the candidate build method**

- **Found during:** Task 2 first GREEN gate.
- **Issue:** A legacy test rejected the word `activate` across the entire `PolicyReindexService`, although approved Plan08 legitimately owns separate activation methods.
- **Fix:** Scoped the assertion to `build_next_document`, preserving the intended proof that candidate build itself cannot activate or share cleanup paths.
- **Files modified:** `tests/eval/test_rag_retrieval_round_isolation.py`.
- **Verification:** Final scoped gate `118 passed`.
- **Committed in:** `c605bfff`.
