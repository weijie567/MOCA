## Critical Issues

### CR-01: Resolving the canonical candidates path can authorize an in-repository copied tree

**Files:** `scripts/reindex_policies.py:154-180`, `scripts/reindex_policies.py:188-205`, `scripts/reindex_policies.py:576-620`, `src/rag/policy_reindex_artifacts.py:48-74`, `src/rag/policy_reindex_artifacts.py:797-819`

**Issue:** The repository-defined path is passed through `resolve(strict=False)` at lines 161-164 before it is compared with `args.artifact_root`. The symlink scan at lines 169-178 then starts from that resolved target. If the lexical candidates path is replaced with a stable symlink to a copied candidate tree elsewhere inside `REPOSITORY_ROOT`, and the caller supplies that resolved target as `--artifact-root`, `requested == canonical` and every scanned target component is a real directory below the repository boundary. `_SecureReviewedArtifactIO` subsequently opens the resolved target with no-follow semantics, which does not reveal that repository authority was reached through a different lexical path. Descriptor/state/budget validation can all succeed against the self-consistent copy, while the attempt scan sees only reservations copied into that tree. Omitting prior attempts permits a fresh ordinal and reaches provider construction for the unchanged DB candidate, bypassing `max_build_executions_per_document=2`.

**Fix:** Preserve the repository-defined candidates path lexically. Require the caller's absolute, non-resolved path to equal that exact lexical path; reject every symlink component between a pinned repository-root descriptor and the candidates directory; and open/retain that relative root chain component-by-component with `O_DIRECTORY|O_NOFOLLOW` instead of resolving it to a target before authority is established. Add an adversarial case in which the canonical candidates path and each relative-path ancestor are symlinked to a copied in-repository tree, then try both the lexical symlink path and the resolved target. Every case must fail before reservation and provider construction.
