## Critical Issues

### CR-01: The lexical root check can race the full-path root open and pin a copied candidate tree

**Files:** scripts/reindex_policies.py:155-220, scripts/reindex_policies.py:591-630, src/rag/policy_reindex_artifacts.py:48-74, src/rag/policy_reindex_artifacts.py:236-265

**Issue:** _require_real_directory_ancestors() checks components with independent lstat calls, returns, and then _SecureReviewedArtifactIO.__enter__() opens self.root as one full pathname. O_NOFOLLOW protects only the final component; it does not stop a relative ancestor becoming a symlink between the check and open. An executor can temporarily redirect an ancestor to a copied tree, let line 59 pin the copy, and restore the real ancestor before _reviewed_descriptor() repeats the lexical scan. verify_namespace() reopens only from that copied root_fd, never from a pinned repository-root descriptor. Descriptor/state/budget validation and reservation remain self-consistent inside the copy, which can omit consumed attempts and bypass max_build_executions_per_document=2.

**Fix:** Open and retain the repository-root descriptor for the whole reviewed command. Open every REVIEWED_CANDIDATE_RELATIVE_ROOT component relative to it with O_DIRECTORY and O_NOFOLLOW, and pass the resulting descriptor into the secure namespace. Before reservation and provider construction, reopen the complete repository-root-to-run chain and compare every pinned (st_dev, st_ino). Add adversarial cases that swap each root ancestor after lexical validation but before root open, restore it before descriptor load, and prove zero copied-tree descriptor/reservation/provider calls.

### CR-02: The A-B recovery cap can be reset by replacing its unpinned root or attempts directory

**Files:** src/rag/evaluation/token_chunk_ab.py:78-114, src/rag/evaluation/token_chunk_ab.py:1607-1737, src/rag/evaluation/token_chunk_ab.py:2516-2536, scripts/eval_rag_token_chunk_ab.py:259-357, scripts/eval_rag_token_chunk_ab.py:900-941

**Issue:** require_canonical_recovery_root() performs a path snapshot and returns a resolved Path without retaining a repository/root descriptor. reserve_recovery_attempt() separately checks symlinks, lists attempts_root, and publishes through _write_create_only_bytes() with pathname mkdir/mkstemp/link calls. Neither the root nor attempts-parent inode is pinned or revalidated. After the symlink check, replacing an exhausted recovery-budgets/<budget>/attempts directory with an empty real directory makes the scan report ordinal 1; the reservation is accepted, reserve_then_create_provider() only rechecks candidate time/bytes, and the provider factory executes. Replacing a canonical-root ancestor during the two resolve() calls likewise retains a copied root after the lexical path is restored.

**Fix:** Give the production A-B command a retained secure namespace anchored at a repository-root descriptor. Open the A-B root, budget directory, and attempts directory component-by-component with O_DIRECTORY and O_NOFOLLOW; list and create-only publish through the same attempts-parent descriptor; then reopen from the repository root and compare all identities before returning the reservation and before provider_factory(). Safely reconcile a stable real-directory replacement only by linking the same reservation into a freshly verified canonical parent and refusing the current provider execution. Add root-ancestor, root-directory, and attempts-parent directory/symlink substitution cases.
