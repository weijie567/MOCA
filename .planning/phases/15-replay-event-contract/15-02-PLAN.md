<architecture_alignment>
## Architecture Alignment

Service ownership:
- `src/replay/service.py` owns append, sequence allocation, V3 projection, and event-store reads.
- `src/replay/validators.py` already owns the baseline `REPLAY_EVENT_TYPES` enum from Plan 15-01. This plan extends it with operation-agnostic field validation, redaction guard, and retention defaults.
- `src/agent/events.py` remains a compatibility import surface for Phase 10-14 code but delegates to `ReplayService`.

Allocator model:
- Keep the current advisory-lock plus `max(sequence)+1` model.
- Do not introduce `AgentRun.next_event_sequence`.
- Do not introduce a dedicated counter table.
- This wave tests graph/tool/RAG, memory_write, approval/API, action draft, and replay/backfill writer surfaces. Plan 15-04 is the canonical lifecycle/finalizer writer coverage once `RunLifecycleService` exists.

Retention/redaction:
- Default retention classification for every known event type must be explicit.
- Every new event type accepted in Phase 15 must define a redaction and retention rule.
- Reject keys including `raw`, `data`, `arguments`, `prompt`, `raw_prompt`, `raw_args`, `raw_payload`, `raw_tool_output`, `secret`, `secrets`, `credential`, `credentials`, and `pii`.
</architecture_alignment>
