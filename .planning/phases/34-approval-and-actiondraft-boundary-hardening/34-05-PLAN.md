<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| graph trusted result -> action_draft node | Approval or auto binding authorizes draft creation. |
| action_draft node -> ToolPlatform/ActionService | Node-only write tool crosses into durable draft persistence. |
| draft persistence -> user/prompt projections | Stored draft material is summarized for response, trace, and working state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-05-01 | Spoofing | `src/agent/nodes/action_draft.py` | mitigate | Accept only service-produced approval_result or strict `auto_allowed_action_binding.v1` matching tenant/run/hash/snapshot/target refs. |
| T-34-05-02 | Tampering | `src/actions/service.py` | mitigate | Validate exact approval or auto binding against persisted snapshot and approval/draft binding fields before insert/reuse. |
| T-34-05-03 | Repudiation | `src/repositories/action_draft_repo.py` | mitigate | Include approval revision or auto marker plus action payload hash in idempotency key and compare Phase 34 binding fields on reuse. |
| T-34-05-04 | Information Disclosure | `src/agent/working_state.py` | mitigate | Project only safe refs/counts and summaries; raw payload/snapshot/approval bodies remain excluded. |
| T-34-05-05 | Elevation of Privilege | no-real-execution boundary | mitigate | Static and focused tests forbid external execution/outbox/reconciliation/compensation records and execution-implying wording. |
</threat_model>
