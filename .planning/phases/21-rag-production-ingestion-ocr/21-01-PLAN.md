## Trust Boundaries

| Boundary | Description |
|---|---|
| file metadata -> parser registry | Caller-supplied source type, extension, declared MIME, and file name select parser behavior. |
| parser output -> later persistence | Parsed text and metadata are untrusted until later plans validate and persist source-block/job rows. |
| business artifact metadata -> source guard | Tool/business artifacts must fail before becoming policy parser inputs. |
