<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| file bytes -> native libraries | Untrusted PDFs, DOCX zip containers, and images are opened by parser/OCR libraries. |
| OCR runtime -> parsed blocks | Native OCR output can be low confidence, empty, delayed, or malformed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan | Tests | Residual Risk |
|---|---|---|---|---|---|---|
| T21-01 | T | `safety.py`, parser registry | mitigate | Validate allowlisted extension, declared source type, and file signature before parser execution. | `uv run pytest tests/rag/test_ingestion_safety.py tests/rag/test_pdf_parser.py tests/rag/test_docx_parser.py -q` | Signature detection depends on `filetype` coverage. |
| T21-02 | D | `safety.py`, PDF/DOCX/image adapters | mitigate | Enforce 20MB files, 50 PDF pages, 8000x8000 images, Pillow decompression failures, and DOCX zip ratio checks. | `uv run pytest tests/rag/test_ingestion_safety.py -q` | Highly compressed edge cases may need more fixture expansion after real corpus import. |
| T21-03 | D | `ocr.py`, `pdf.py` | mitigate | Apply parser timeout 30s and OCR timeout 15s/page before DB mutation. | `uv run pytest tests/rag/test_ocr_parser.py tests/rag/test_pdf_parser.py -q` | Native runtime availability differs across developer machines. |
| T21-04 | S/E | adapter text extraction | mitigate | Treat hidden comments/OCR text as untrusted block text; no prompt/API/memory/action/replay use in adapters. | `uv run pytest tests/rag/test_ingestion_safety.py tests/knowledge/test_phase21_boundaries.py -q` | Full surface exclusion verified in Plan 04. |
