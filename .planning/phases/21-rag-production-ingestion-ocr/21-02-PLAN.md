<objective>
Implement source-block aware chunking, retrieval-only enrichment, and atomic parser-aware ingestion.

Purpose: real document parsing is only useful if the block provenance survives chunking and failed ingestion cannot corrupt committed policy evidence.
Output: `chunk_blocks(...)`, table-aware chunk refs, version fingerprinting, and ingestion writes that persist documents, blocks, chunks, and jobs atomically.
</objective>

<scope>

Out of scope: PDF/DOCX/image/OCR adapter internals and provenance lookup API exposure.
</scope>
