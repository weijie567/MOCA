## Sampling Rate

- **After every task commit:** Run the task's focused `UV_CACHE_DIR=/tmp/uv-cache uv run pytest ... -q --tb=short` command; frontend tasks also run the named Vitest file.
- **After every plan wave:** Run all focused files owned by completed plans plus `UV_CACHE_DIR=/tmp/uv-cache uv run ruff check` on changed Python paths.
- **Before `$gsd-verify-work`:** The complete Phase 64.1 safety matrix, frontend test run, and frontend build must be green.
- **Max feedback latency:** 120 seconds for per-task focused checks.

## Required Safety Matrix

| Case | Expected route/terminal | Draft invariant |
|------|-------------------------|-----------------|
| Canonical English/Chinese low action | deterministic allow -> valid capability -> draft -> completed demo | exactly one durable draft |
| Medium action | approval/manual review | none before trusted decision |
| High action | approval required | none before trusted decision |
| Unknown/ambiguous/schema-invalid action | manual review/error; never ordinary completed advice | none |
| LLM timeout/unavailable/invalid schema | deterministic severity or fail-closed fallback | none unless deterministic allow is independently proven |
| Stale revision/version or hash mismatch | stable conflict/closed; no resume | none |
| Cross tenant/run/actor/merchant/handler capability | authorization failure | none |
| Expired/replayed capability | stable closed or explicit idempotent same-use result | no new draft |
| Draft store/tool/audit failure | error/manual terminal; no successful SSE/final | none or rolled-back partial row |
