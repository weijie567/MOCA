## Phase Boundary

Phase 24 review 已修复 `/agent-runs` completed finalizer 中 `memory_write` rollback 污染 assistant message / rolling summary 的问题，但隔离逻辑目前内联在 `src/api/services/agent_run_memory.py`。本 phase 将这条规则制度化为通用 helper/policy，并补最小 trace metrics。
</domain>

<decisions>
## Implementation Decisions

### Isolation Policy

- Memory side effect 默认不能污染主业务事务。
- 对会 rollback/timeout/fallback 的 memory write，调用方应使用独立 `AsyncSession` 或等价隔离 helper。
- Helper 不直接依赖 agent 节点，避免 memory 基础层反向 import agent。

### Observability MVP

- Finalizer trace metrics 至少包含：
  - `memory_write_status`
  - `memory_write_reason_code`
  - `memory_write_duration_ms`
  - `slot_count`
  - `fallback_reason`
  - `pii_decision`
  - `pii_classification`
- 禁止记录 raw final response、raw slots、raw tool data、private/debug/authority body。
</decisions>
