<architecture_alignment>
## Architecture Alignment

Owner and contract first:
- Canonical owner packages: `src/actions` emits draft-created event refs, `src/agent/events.py` owns minimal event registration, and trace repository/router own read projection only.
- Contract: `action_draft_created` uses existing minimal event envelope with safe refs and redacted payload; `/trace` includes `draft_outcome` without raw `ActionDraft.payload`.

Move/rewrite to owner:
- Register `action_draft_created` in the minimal event registry.
- Emit the event from the action service after a new draft row is created.
- Extend trace reads in the existing `/trace` compatibility read model; do not add replay/event-store read switch.

Delete/quarantine old paths:
- Do not emit `action_execution_*` events in demo mode.
- Do not include raw action payload, raw tool args, full `ActionDraft.payload`, external refs, outbox, reconciliation, compensation, or adapter dispatch details.
- Do not add ReplayEventV3, `/replay`, lifecycle finalizer, retention model, or event-store-first trace read in Phase 14.

Boundary tests before expansion:
- Event tests must fail on raw-like payload keys and unregistered external execution event types.
- Trace tests must prove `draft_outcome` is present and raw `payload` is absent.
</architecture_alignment>
