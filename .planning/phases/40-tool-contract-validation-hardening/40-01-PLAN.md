<objective>
Replace the remaining generic action output contract with a strict schema for `create_coupon_grant_draft`.

Purpose: action draft output flows into approval/action execution handling, so it is the highest-risk remaining generic output schema. The schema must match the real success payload from `src/actions/service.py`.
Output: catalog schema and tests that accept current valid action draft payloads and reject extra/raw or incomplete action output.
</objective>
