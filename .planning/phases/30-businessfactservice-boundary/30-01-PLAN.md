## Trust Boundaries

| Boundary | Description |
| --- | --- |
| ToolCallContext -> BusinessFactService | Trusted identity/scope enters the domain service; user/model payload must not override it. |
| BusinessFactService -> adapters | Private adapter calls may see raw rows/payloads; service output must be strict and no-leak. |
