# 08-03 PLAN: Citation Membership Validator (evidence_id)

<objective>
Implement the deterministic citation membership validator in `src/knowledge/citation.py` (D-C1/D-C2/D-C3). It maps each structured material claim to a list of cited `evidence_id`s and verifies that every cited `evidence_id` is present in the run's `evidence_refs`. A missing or wrong reference fails citation membership for that claim. This is membership only — NOT semantic claim support.

The validator produces the `claim_results` structure and `CitationValidationResult` defined in 08-01, keying on `evidence_id` (NOT the legacy bare `chunk_id`). The existing `src/rag/citation_validator.py` is left in place as a legacy adapter internal (D-C3) and is NOT modified by this plan; the new validator supersedes it for the facade path.

This plan does NOT modify `src/rag/*`, `src/agent/*`, or the facade; the node wiring that calls this validator with real claims is 08-04.
</objective>

  ```python
  from __future__ import annotations

  from src.knowledge.schemas import (
      ClaimResult,
      CitationValidationResult,
      EvidenceRefV1,
  )

  CITATION_VALIDATOR_VERSION = "citation_validator.v2"


  def validate_membership(
      claims: list[dict],
      evidence_refs: list[EvidenceRefV1],
  ) -> CitationValidationResult:
      """Deterministic citation membership: every cited evidence_id must be
      present in evidence_refs. Membership != semantic support."""
      present = {ref.evidence_id for ref in evidence_refs}
      claim_results: list[ClaimResult] = []
      all_member = True
      for claim in claims:
          cited = list(claim.get("cited_evidence_ids") or [])
          missing = [eid for eid in cited if eid not in present]
          is_member = bool(cited) and not missing
          if not is_member:
              all_member = False
          claim_results.append(
              ClaimResult(
                  claim_id=str(claim.get("claim_id")),
                  claim_text=str(claim.get("claim_text") or ""),
                  cited_evidence_ids=cited,
                  is_member=is_member,
                  missing_evidence_ids=missing if cited else [],
              )
          )
      return CitationValidationResult(
          validator_version=CITATION_VALIDATOR_VERSION,
          claim_results=claim_results,
          is_valid=all_member and len(claim_results) > 0,
      )
  ```

  Notes:
  - Accept `claims` as a list of dicts (the node builds these from the recommendation draft in 08-04); keeping it dict-based avoids coupling to the recommendation schema here.
  - `evidence_refs` is `list[EvidenceRefV1]` (or any objects exposing a `.evidence_id` attribute). The validator iterates `ref.evidence_id`; callers MUST pass objects, never a bare list/set of `evidence_id` strings. Document this in the function docstring/signature.
  - An empty `claims` list yields `is_valid=False` (a policy answer must carry at least one validated material claim — mirrors the legacy "no citations" failure intent). Document this explicitly.
  - No LLM, no DB, no network.
