<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| retrieved refs -> Wave 0 tests | Candidate `EvidenceRefV1` values can be stale, forged, wrong-tenant, wrong-scope, hash-invalid, or latest-version-invalid until canonical validation proves otherwise. |
| generated claims -> verifier tests | Model-produced claim text and citations are untrusted until Level 1/2/3 verification produces a support outcome. |
| verifier status -> route tests | Safety routes must be produced by backend code, not by model output. |
| debug/provenance/provider internals -> tests | Tests must assert unsafe internals stay out of ordinary prompts, final responses, memory, replay, and action snapshots. |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-22-01 | high | Information Disclosure / Elevation of Privilege | ContextBuilder evidence input tests | mitigate/block | Add RED tests that wrong-tenant, unauthorized, scope-invalid, and latest-version-invalid evidence cannot become included bundle evidence or claim support. |
| T-22-02 | high | Tampering | Evidence validation test fixtures | mitigate/block | Add RED assertions for canonical content hash mismatch, stale refs, duplicate keys, and latest/current policy version mismatch exclusion reason codes. |
| T-22-03 | high | Tampering / Information Disclosure | Prompt-safe context and provenance labels | mitigate/block | Add RED leakage and projection assertions that raw policy/OCR/provenance internals are not emitted as prompt/final-response authority. |
| T-22-04 | high | Spoofing / Tampering | MaterialClaim authority tests | mitigate/block | Add RED authority-boundary tests requiring Tool System refs for business facts and active policy bundle evidence for policy claims. |
| T-22-05 | high | Elevation of Privilege | Route matrix tests | mitigate/block | Add RED tests that deterministic backend routing maps non-allow outcomes and exposes `regenerate_route` only as a route value. |
| T-22-06 | high | Tampering / Elevation of Privilege | Action recommendation verification tests | mitigate/block | Add RED tests that unsupported action recommendation dependencies produce non-allow outcomes before action creation. |
| T-22-07 | high | Information Disclosure | Semantic verifier fake-provider tests | mitigate/block | Add RED tests that verifier failures expose only redacted status/reason codes/metrics/safe refs, never raw prompts or private reasoning. |
</threat_model>
