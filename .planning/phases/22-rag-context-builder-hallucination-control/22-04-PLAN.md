<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output -> MaterialClaim | Claims and citations generated by a model are untrusted until strict DTO validation and verifier checks complete. |
| active context bundle -> verifier | Only Plan 22-03 current allowed evidence and safe Tool System refs can satisfy claim authority. |
| semantic provider -> verifier result | Provider output is untrusted and must be parsed through strict DTOs, budgets, timeout handling, and fail-closed conversion. |
| verifier result -> downstream route | Verifier exposes typed support outcomes, not direct action permission. Later routing owns allow/manual/refusal decisions. |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-22-01 | high | Information Disclosure / Elevation of Privilege | Level 1 policy gates | mitigate/block | Require active bundle membership plus tenant/scope/current validation before policy claims can be supported. |
| T-22-02 | high | Tampering | Level 1 hash/current gates | mitigate/block | Treat hash mismatch, stale refs, duplicate evidence keys, and latest-version-invalid evidence as unsupported/excluded reason codes. |
| T-22-03 | high | Tampering / Information Disclosure | Level 2/3 support text | mitigate/block | Use bounded verifier inputs from safe projections and never expose raw OCR/provenance/unbounded policy text in ordinary outputs. |
| T-22-04 | high | Spoofing / Tampering | business fact claims | mitigate/block | Require BusinessFactRefV1 or safe ToolResultV2 refs from trusted context; reject policy/memory/model support for business facts. |
| T-22-05 | high | Elevation of Privilege | verifier outcomes | mitigate/block | Do not let verifier or model choose safety routes; emit typed outcomes for deterministic route map in Plan 22-05. |
| T-22-06 | high | Tampering / Elevation of Privilege | action recommendation claims | mitigate/block | Require supported policy and business dependencies; unsupported dependencies produce non-allow verifier status. |
| T-22-07 | high | Information Disclosure | semantic provider handling | mitigate/block | Redact provider prompts/private reasoning, fail closed on timeout/error/malformed output, and verify leakage tests. |
</threat_model>
