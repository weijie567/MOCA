    - invoke_tool delegates to registry.invoke and retries only when result.retryable is true.

    - Attempts run from current ctx.attempt through ctx.max_attempts inclusive; attempt greater than max never invokes registry.
    - Every retry uses an updated attempt but the same request_id/tool_call_id/trace_id and trusted identity/scope.
    - Model/request-provided merchant categories absent from trusted ctx.merchant_scope["categories"] and merchant IDs outside ctx.merchant_scope["merchant_ids"] are denied before registry/adapter execution.
    - No max_iterations, routing, tool selection, or multi-tool loop exists in this service.

  <action>
Create `BusinessToolService` with a constructor taking `ToolRegistry`, plus a default construction seam that assembles a `ToolRegistry` populated with the real Phase 09-03 `get_order_adapter`, `get_refund_case_adapter`, and `get_ticket_adapter` functions and their Plan 09-02 descriptors. This plan owns the registry↔adapter composition root; callers must not have to hand-assemble the live read registry. Implement `async def invoke_tool(self, name: str, args: dict[str, Any], ctx: ToolCallContext) -> ToolResultV2`.

Before calling registry, deny empty/None `ctx.merchant_scope` with `status="permission_denied"`, `ToolError(code="EMPTY_MERCHANT_SCOPE", safe_message="Merchant scope is required", retryable=False, source="caller")`, `data=None`, empty refs, `latency_ms=0`, `audit_ref=None`. Also validate any model/request-provided merchant category and merchant ID in `args` against the trusted `ctx.merchant_scope` dict: an unknown category or an ID outside `merchant_ids` returns permission_denied before registry/adapter execution. Missing dimensions do not widen access, and all provided dimensions must match. If `ctx.attempt > ctx.max_attempts`, return a safe exhausted result without invoking registry.

Otherwise loop attempts from `ctx.attempt` to `ctx.max_attempts`, using `ctx.model_copy(update={"attempt": attempt})`; call `registry.invoke(name, args, attempt_ctx)`. Return immediately on non-retryable result or success. Retry only `result.retryable is True`; after the final attempt return the final typed result. Preserve the original `tool_call_id` on every copied context. Do not add `max_iterations` or graph routing.
