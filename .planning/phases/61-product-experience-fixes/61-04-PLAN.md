<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Slot state -> investigate tool args | Only validated active metric slots can become tool args. |
| Tool result -> final response | Final response can format typed metric facts but cannot fetch or recompute them. |
| Final state -> SSE payload | SSE projects only user-safe result type and summary fields. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-61-04-01 | Tampering | investigate planner step | mitigate | Existing planner validation plus metric allowlist and strict tool schema. |
| T-61-04-02 | Information disclosure | metric final response | mitigate | No-leak branch for permission-denied metric results and response tests. |
| T-61-04-03 | Repudiation | SSE result projection | mitigate | Stable `response_kind` and metric metadata in redacted payloads. |
| T-61-04-04 | Spoofing | metric answer authority | mitigate | Final response reads only BusinessFactService tool result, not RAG/memory/LLM claims. |
</threat_model>
