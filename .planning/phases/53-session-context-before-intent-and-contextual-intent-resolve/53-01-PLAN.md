| Boundary | Description |
|----------|-------------|
| user text -> contextual_intent_resolve LLM adapter | Untrusted ordinary chat text and structured model output cross into AgentState. |
| contextual_intent_resolve -> route_after_contextual_intent | Candidate intent fields cross into deterministic router decision logic. |
| safety_pre_route -> session_context_load | Phase 52 request-risk output determines whether same-thread context may load before intent. |

| T-53-01-02 | Spoofing / Elevation of Privilege | `route_after_contextual_intent` | mitigate | Treat ordinary-chat `requested_operation == "approval_decision"` as invalid and route to `clarification_gate`; do not let LLM output choose graph routes per D-17. |
| T-53-01-03 | Reliability / Route Drift | `src/agent/routing.py`, `src/agent/intent_policy.py` | mitigate | Replace active `session_memory_load` route values with `extract_slots` and assert router totality in `tests/test_graph_routing.py` and `tests/agent/test_intent_routing.py` per D-15/D-16. |
