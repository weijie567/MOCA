| safety_pre_route -> session_context_load | A safe or safety_sensitive request may now load same-thread context before intent classification. |
| session_context_load -> contextual_intent_resolve | Same-thread context crosses into the LLM input/intent adapter boundary. |
| graph routing -> legacy extract_slots | Slot-required canonical intent output temporarily enters the Phase 54-owned legacy slot node. |
