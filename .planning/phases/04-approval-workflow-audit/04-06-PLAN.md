- LR-01: Standard refund, amount < 500, merchant not high-risk → approval_required == False

- Insufficient evidence: recommended_action = "insufficient_evidence" → approval_required == False

**Interception rate calculation:**
```python
def test_interception_rate_100_percent():
    high_risk_cases = [hr01_state, hr02_state, hr03_state]
    intercepted = 0
    for state in high_risk_cases:
        result = await assess_risk_and_approval(state)
        if result["risk_assessment"]["approval_required"]:
            intercepted += 1
    assert intercepted == len(high_risk_cases), f"Interception rate: {intercepted}/{len(high_risk_cases)}"
```

Also test `route_after_risk` function directly with each high-risk state to confirm it returns "approval_gate".
