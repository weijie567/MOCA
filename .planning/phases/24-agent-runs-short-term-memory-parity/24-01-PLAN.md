<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> POST `/api/v1/agent-runs` | User query and thread_id enter authenticated backend; user cannot provide trusted conversation IDs. |
| SSE stream -> graph config | Backend-resolved run/message identity crosses into LangGraph config. |
| graph/tool output -> conversation memory | Only prompt-safe summaries may enter conversation/tool memory. |
| terminal finalizer -> SSE final_response | Persistence result must be known before the final answer is emitted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Tampering/Repudiation | `tests/test_agent_runs_api.py` duplicate stream tests | mitigate | RED tests count user, assistant, tool, summary, and session-memory rows before/after duplicate streams. |
| T-24-02 | Repudiation | SSE final-response ordering test | mitigate | RED test requires explicit memory persistence result before `final_response`. |
| T-24-03 | Spoofing/Tampering | graph-config capture test | mitigate | RED test asserts `conversation_thread_id` and `conversation_message_id` are backend-resolved from DB. |
| T-24-04 | Information Disclosure | three-turn smoke and scoped DB assertions | mitigate | RED tests use tenant/user/thread scoped counts and fail if cross-scope context is accepted. |
| T-24-05 | Elevation of Privilege/Tampering | smoke negative authority assertion | mitigate | RED smoke asserts memory is contextual only and cannot satisfy policy/business/action/replay authority. |
| T-24-06 | Repudiation | error/cancel/interrupted test | mitigate | RED test asserts non-completed statuses write no assistant message and no rolling summary. |
</threat_model>
