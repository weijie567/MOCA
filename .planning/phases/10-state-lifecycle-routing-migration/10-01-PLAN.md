<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API/auth → AgentState | Identity (tenant_id/user_id/role/thread_id) injected by trusted config; must never be writable by LLM/user. |
| LLM output → AgentState | `llm_outputs` and intent/structured output cross into state; must use field-by-field replace, never whole-object merge into trusted groups. |
| Prior turn → current turn | Checkpointer carries state across turns; stale ephemeral context must be reset each turn. |
