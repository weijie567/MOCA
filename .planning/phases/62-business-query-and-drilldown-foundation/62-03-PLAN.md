<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ToolPlatform to BusinessFactService | Validated specs cross from tool runtime into business fact execution. |
| BusinessFactService to database | Trusted scope and allowlisted descriptors become SQLAlchemy statements. |
| BusinessFactService result to prompt/tool storage | Runtime data is projected into safe facts and summaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-62-08 | Tampering | `BusinessQueryCompiler` | mitigate | Build only SQLAlchemy expressions from registry descriptors; static tests reject raw SQL and generic list helpers. |
| T-62-09 | Elevation of Privilege | `BusinessFactService.query_business` | mitigate | Derive merchant scope from trusted ToolCallContext before execution; reject untrusted tenant/scope fields. |
| T-62-10 | Information Disclosure | list/detail runtime | mitigate | Scope-before-existence tests assert denied/out-of-scope ids do not appear and detail lookup is not performed before authorization. |
| T-62-11 | Information Disclosure | `ToolResultProjector` | mitigate | Prompt-safe projection strips raw rows, args, payloads, tenant, scope internals, stack traces, and denied identifiers. |
| T-62-12 | Denial of Service | list/cursor runtime | mitigate | Enforce registry max limit, deterministic ordering, and limit-plus-one cursor detection. |
</threat_model>
