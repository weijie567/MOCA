<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user or LLM text to agent parser | Untrusted text is interpreted into candidate slots and must only select registry-known metrics/resources/time presets. |
| registry to tool catalog | Tool schemas must be derived from one backend-owned registry and must not expose arbitrary filters or authority fields. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-62-01 | Tampering | `src/business/query/registry.py` and parser consumers | mitigate | Frozen descriptors plus parity tests make operation/resource/metric/time/status definitions single-source and fail if local copies drift. |
| T-62-02 | Information Disclosure | parser and catalog schema generation | mitigate | Registry excludes tenant, merchant_scope, raw SQL, raw cursor, draft, and execute fields; tests assert business-read taxonomy only. |
| T-62-03 | Denial of Service | list/detail field and limit descriptors | mitigate | Registry describes bounded fields and default limits for later schema/runtime enforcement; no arbitrary field picker is introduced. |
</threat_model>
