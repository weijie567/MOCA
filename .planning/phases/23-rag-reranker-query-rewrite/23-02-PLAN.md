```python
class RewriteExpansion(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)
    query: str
    source: Literal["domain_synonym", "intent_normalization", "merchant_support_alias"]
    matched_terms: tuple[str, ...] = ()

class QueryRewritePlan(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)
    original_query: str
    rewritten_queries: tuple[str, ...] = ()
    expansions: tuple[RewriteExpansion, ...] = ()
    skip_reason: Literal[
        "already_specific", "out_of_domain", "unsafe_query", "missing_trusted_context",
        "disabled", "budget_exceeded", "error"
    ] | None = None
    safe_summary: str | None = None
    trigger_terms: tuple[str, ...] = ()
    source: Literal["rule_default"] = "rule_default"
    config_version: str = QUERY_REWRITE_CONFIG_VERSION
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user query -> rewrite planner | Untrusted natural language is transformed into internal retrieval expressions. |
| trusted context -> rewrite planner | Trusted tenant/scope/role filters are read-only inputs and must not be created or changed by rewrite. |
| rewrite planner -> diagnostics/search result | Only bounded safe summary may leave the rewrite module. |

| T-23-02-02 | Tampering | rewrite expansions | mitigate | Task 1 bounds rewrite count/chars and preserves `original_query`; Task 2 uses deterministic local synonyms only. |
| T-23-02-03 | Information disclosure | `safe_rewrite_summary` | mitigate | Task 2 requires summary-only output and raw prompt/provider/private reasoning sentinels. |
