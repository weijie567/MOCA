```python
class RerankCandidate(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)
    candidate_id: str
    doc_key: str
    chunk_id: str
    policy_version: str
    title: str
    section: str
    text_snippet: str
    baseline_score: float
    baseline_rank: int
    selected_by: tuple[str, ...] = ()
    rrf_score: float | None = None

class RerankConfig(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)
    config_version: str = RERANK_CONFIG_VERSION
    provider_enabled: bool = RERANK_PROVIDER_ENABLED
    max_candidates: int = RERANK_MAX_CANDIDATES
    text_max_chars: int = RERANK_TEXT_MAX_CHARS
    timeout_seconds: float = RERANK_STAGE_TIMEOUT_SECONDS
    provider_max_retries: int = RERANK_PROVIDER_MAX_RETRIES

class RerankerProviderAdapter(Protocol):
    async def rerank(self, query: str, candidates: Sequence[RerankCandidate], config: RerankConfig) -> Sequence[ProviderRerankScore]: ...

class DefaultLocalReranker:
    async def rerank(self, query: str, candidates: Sequence[RerankCandidate], config: RerankConfig) -> RerankOutput: ...
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| merged retrieval candidates -> reranker | Bounded internal candidates become reranker inputs before evidence construction. |
| optional provider adapter -> reranker | Optional untrusted provider output can reorder candidates only after validation and must fall back safely. |
| reranker diagnostics -> eval/maintainer surfaces | Score components and fallback metadata are internal/eval-only and cannot extend evidence identity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-04-01 | Tampering | provider scores | mitigate | Task 3 validates provider output candidate IDs, uniqueness, numeric bounded scores, and budget limits before accepting any order. |
| T-23-04-02 | Information disclosure | reranker inputs | mitigate | Task 2 passes bounded snippets and excludes raw source-block/OCR/parser/tool/business/private/provider payloads. |
| T-23-04-03 | Denial of service | provider adapter | mitigate | Task 3 uses timeout/retry/candidate/text budgets and defaults provider disabled. |
| T-23-04-04 | Elevation of privilege | reranker score authority | mitigate | Task 2 keeps reranking before `EvidenceRefV1`; Task 3 records scores as diagnostics only; Phase 22 verifier remains support authority. |
</threat_model>
