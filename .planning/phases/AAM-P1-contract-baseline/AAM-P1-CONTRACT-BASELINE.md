# AAM-P1 Contract Baseline

This docs-only baseline separates current MOCA evidence from Agent Architecture Migration target contracts. A later-phase owner assignment is planning coverage, not proof that the target is implemented.

For every `DEFERRED_WITH_OWNER` row, deferral is non-blocking for AAM-P1 because AAM-P1 is docs-only; the named dependency and acceptance gate control the owner phase. Every `PARTIAL` row is non-blocking for AAM-P1 because the baseline records the gap, owner, dependency, and acceptance gate without claiming implementation.
