---

## Sampling Rate

- **After every task commit:** Run the task's focused command from the map plus the narrowest relevant Ruff target.
- **After every plan wave:** Run the full focused command.
- **Before `$gsd-verify-work`:** Phase regression command and repository-required Ruff gates must be green; a provider baseline may be quality-red but cannot be missing or mislabeled when prerequisites are available.
- **Max feedback latency:** 5 minutes for deterministic task sampling; provider/OCR execution is excluded from this latency target and reports its own timings.
