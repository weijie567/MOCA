# Phase 64.3 Plan Review Decisions

## Evidence Checked

- A two-run isolated probe executed the current `evaluation/rag_sources/build_fixtures.py` twice with identical Markdown/tool/font inputs and a wall-clock gap. All six PDF SHA-256 values and the manifest SHA-256 changed while all three Markdown hashes remained identical. The current generator is therefore not byte-deterministic.
- `src/rag/ingestion.py` creates/commits the job trace before parsing, but current document/block/chunk/immutable writes share one final transaction and one commit. A crash cannot legitimately commit blocks without chunks through the current implementation. A crash can leave a job-only reservation, or can occur after the complete final projection commit but before the evaluation owner CAS advances.
- `KnowledgeSearchResult` exposes status, evidence refs, rewrite, score, threshold, and citation validation; the richer fallback/rewrite/rerank diagnostics live on `PolicyRetrievalRun`. A recording delegate around the real engine is required if the evaluator must capture those details while still routing the query through `PolicyKnowledgeService.search`.
- Current shell preflight: Tesseract and `chi_sim`/`eng` are installed; `DASHSCOPE_API_KEY`, `RAG_FORMAT_PARITY_RUN_TOKEN`, and `EVIDENCE_ROLLOUT_VERSION` are not configured; no ready local PostgreSQL evaluation runtime was detected. No secret value was read or printed.
- Plan 05's `git diff 8392b0b...HEAD` would omit current uncommitted task edits when task verification runs before commit. `git diff 8392b0b -- <paths>` is required to compare the working tree plus index and committed changes to the stable base.
