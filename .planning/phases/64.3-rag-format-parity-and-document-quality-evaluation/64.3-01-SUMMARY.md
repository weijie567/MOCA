## Decisions Made

- Keep current checked-in Markdown bytes canonical because repository history contains no earlier Markdown revision and the introduction commit already disagrees with the stale manifest hashes.
- Publish only a complete three-policy family; no partial-topic CLI or hash-refresh helper can create an apparently valid mixed generation.
- Use ReportLab invariant mode at the `SimpleDocTemplate` owner and fixed Pillow UTC `struct_time`, because Canvas defaults and tuple dates do not produce deterministic metadata.
- Preserve source RGB raster pages at fixed quality/subsampling and derive the scanned PDF resolution from exact A4 points, producing same-size pages without reintroducing a text layer.
- Treat differing tool/font/profile identity as a new baseline input, never as permission to reuse prior fixture bytes.

## Issues Encountered

- Pillow PDF dates require `time.struct_time`; a plain tuple fell through to byte conversion and failed on the year value.
- ReportLab `BaseDocTemplate` passes its own invariant/page-compression values to Canvas, so the deterministic settings had to live on the document owner rather than only in a partial canvas factory.
- Rounded 200-DPI raster geometry initially produced a one-pixel A4 height mismatch; deriving x/y PDF resolution from the exact A4 MediaBox removed it.
- Extra grayscale autocontrast and lower JPEG quality inflated paired-page pixel differences; retaining RGB raster data at fixed quality kept all 30 page pairs below a 5/255 grayscale mean-difference bound.
