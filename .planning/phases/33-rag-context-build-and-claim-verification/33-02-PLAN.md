<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| investigate -> rag_context_build | Candidate evidence refs cross from retrieval output into deterministic validation. |
| rag_context_build -> recommendation_generation | Only verified prompt projection may enter generation. |
| router -> graph edge | Side-effect-free route keys control whether unsafe states reach generation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-33-02-01 | Tampering / Elevation of privilege | `rag_context_build` | mitigate | canonical re-fetch through `KnowledgeService.build_verified_context`; invalid hash/scope/version/effective-date candidates become rejected refs and status `invalid_hash`, `invalid_scope`, `stale`, or `conflict`. |
| T-33-02-02 | Information disclosure | candidate refs | mitigate | working-state and prompt projections reject candidate-only refs; leakage tests scan prompt/action/final surfaces. |
| T-33-02-03 | Denial of service / Tampering | `route_after_rag_context` | mitigate | total deterministic router over all ten statuses with malformed state fallback to `final_response`. |
| T-33-02-04 | Elevation of privilege | graph edge wiring | mitigate | graph tests assert invalid/partial/action-bound package states cannot reach `generate_recommendation`. |
| T-33-02-05 | Information disclosure | raw package debug projection | mitigate | package debug/rejected refs stay out of working-state prompt projection; ordinary surfaces use prompt/safe refs only. |
</threat_model>
