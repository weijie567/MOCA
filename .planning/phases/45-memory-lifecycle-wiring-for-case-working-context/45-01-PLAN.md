<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| graph/API state -> lifecycle adapter | Untrusted or model-influenced state is filtered before it can select a case scope. |
| lifecycle adapter -> memory context bundle | CWC enters agent state only as contextual-only memory, not authority. |
| CWC row -> prompt/runtime state | Stored working context is projected through prompt-safe refs/status, not raw authority bodies. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-01 | S/I | `trusted_case_ref_from_state`, `resolve_case_id` | mitigate | Accept case refs only from `active_slots`/`extracted_slots` plus terminal business_context when explicitly enabled; resolve through tenant-scoped `resolve_case_id`; ignore `candidate_slots`, `session_memory`, and `case_memory`. |
| T-45-02 | E | `MemoryContextBundle`, CWC refs/status | mitigate | Add only `authority_class="contextual_only"` models; tests forbid imports of EvidenceRefV1, BusinessFactRefV1, approval, action, and replay DTOs. |
| T-45-03 | I | CWC active payload projection | mitigate | Project active rows through `hydrate_content` plus CaseWorkingContextRef; no policy body text, raw tool payload, approval/action body, or replay/debug blob fields are added in this plan. |
| T-45-04 | D | terminal response path | mitigate | This plan creates explicit status values consumed by 45-03; terminal CWC failures must be representable as `status="error"` / `reason_code` without exception-driven response loss. |
| T-45-05 | R | lifecycle status/audit bridge | mitigate | Status carries run_id, case_id, resolve/link/read/write status, and reason_code so later audit/replay projections are traceable and not silent. |
| T-45-06 | T | CWC conflict overwrite | mitigate | Adapter exposes status/ref fields needed for 45-03 expected_version/conflict handling; no write path is introduced before conflict behavior is planned. |
</threat_model>
