<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| final_state -> CWC projection | Model/tool/run state is reduced to deterministic refs/summaries before persistence. |
| finalizer -> CWC write service | Terminal lifecycle calls an audited memory service after response artifacts are durable. |
| CWC service result -> finalizer trace | Memory side-effect status is reported without changing the user-visible response. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-01 | S/I | `write_after_terminal_success` | mitigate | Resolve case through tenant-scoped `resolve_case_id`; link by tenant/user/thread/run; CWC service asserts run and case belong to tenant. |
| T-45-02 | E | terminal CWC content | mitigate | Projection writes only CaseWorkingContextContentV1 with `authority_class="contextual_only"`; it never emits evidence, policy, approval, action, or replay authority fields. |
| T-45-03 | I | deterministic projection | mitigate | Use prompt-safe summaries and refs only; exclude raw tool data, policy body text, approval/action bodies, safety snapshot bodies, replay/debug blobs; classify PII before service write. |
| T-45-04 | D | `finalize_completed_agent_run_memory` | mitigate | CWC write runs after assistant message/thread summary commit; all CWC write exceptions are caught into side-effect status so user response artifacts survive. |
| T-45-05 | R | CWC write audit/replay | mitigate | Source refs bind run_id, agent_run_id, business_object_type=refund_case, and business_object_id=case_id; service emits `memory_write_events(memory_type="case_working_context")`. |
| T-45-06 | T | CWC expected_version | mitigate | Adapter reads active version and passes expected_version; service conflict returns skip/conflict status and finalizer records it without overwrite. |
</threat_model>
