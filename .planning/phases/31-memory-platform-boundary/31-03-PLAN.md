<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| memory facade -> existing services | MemoryContextService composes existing services without direct repository/table ownership. |
| memory DTO -> authority consumers | Memory refs/status refs are typed contextual-only DTOs and must not structurally match authority DTOs. |
| storage contract -> graph contract | Persistence names remain storage/history; graph-facing target names are facade/projection concerns. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-cross-merchant | I | `MemoryContextService` | mitigate | Facade status DTOs carry tenant/scope metadata; Plan 31-05 adds trusted-scope enforcement before retrieval. |
| T-31-authority-forgery | S/T | `src/memory/context_refs.py` | mitigate | DTOs hard-code `authority_class="contextual_only"` and avoid authority DTO imports. |
| T-31-pii-leakage | I | `SessionContextMemory` projection | mitigate | Projection copies only existing prompt-safe bundle surfaces and does not expose raw repository rows. |
| T-31-tombstone-revival | T/R | facade lifecycle boundary | mitigate | Facade composes existing lifecycle services and leaves tombstone filtering to current long-term/case services; Plan 31-06 projects decisions. |
| T-31-replay-confusion | R/T | status refs | mitigate | Status refs are contextual-only DTOs; no `ReplayEventV3` import or replay event registration is added. |
| T-31-write-rollback | D/T | `project_memory_write_decision` | mitigate | Pure decision projection records status/fallback metadata without changing transaction behavior. |
</threat_model>
