| Boundary | Description |
|----------|-------------|
| memory write side effect -> main path | Write failures/timeouts must not roll back final response, approval, or action state. |
| memory contextual refs -> claim verifier | Contextual-only memory refs/status refs must be rejected as authority by verifier defenses. |
| validation suite -> local DB | DB-backed tests must be serial to avoid shared metadata races. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-cross-merchant | I | final focused suite | mitigate | Final serial suite includes merchant-scope static guard and reviewed memory cross-merchant tests from Plan 31-05. |
| T-31-authority-forgery | S/T | `MaterialClaimVerifier` | mitigate | Verifier rejects `authority_class="contextual_only"` refs/status refs with explicit non-authority reason codes. |
| T-31-pii-leakage | I | final memory suite | mitigate | Final lifecycle suite includes non-prompt-safe PII exclusion and prompt projection sanitization checks. |
| T-31-tombstone-revival | T/R | reviewed memory lifecycle | mitigate | Final lifecycle tests include tombstone/delete/supersede non-revival checks. |
| T-31-replay-confusion | R/T | memory status refs | mitigate | Verifier and tests reject memory status refs as `ReplayEventV3`; no replay event coverage is implemented in this phase. |
| T-31-write-rollback | D/T | `memory_write` | mitigate | `memory_write_decision.v2` records timeout/error fallback while preserving final response and legacy result. |
