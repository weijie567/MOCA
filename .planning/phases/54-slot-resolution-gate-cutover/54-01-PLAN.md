<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM structured output -> deterministic slot resolver | LLM may propose extracted values, but deterministic code decides slot satisfaction and route eligibility. |
| session context -> active slot inheritance | Same-thread session slots cross into current-turn state only after tenant/user/thread/freshness/intent compatibility checks. |
| current user query -> invalidation/conflict detector | User text can invalidate or replace inherited slots and must not be ignored. |
| slot gate -> clarification route | Missing, stale, incompatible, invalidated, unresolved conflicting, malformed, or error state must fail closed before investigation. |
| canonical node -> legacy compatibility fields | New provenance is additive; existing downstream fields stay available until explicit cleanup. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-01-01 | Elevation of Privilege | `slot_resolution_gate` LLM extraction | mitigate | LLM output only populates candidates/extracted values; `SlotPolicyRegistry` and deterministic resolver decide `active_slots`, `missing_required_slots`, and route decision per D-08. |
| T-54-01-02 | Information Disclosure | inherited session slots | mitigate | Require tenant/user/thread/freshness/intent compatibility; tests cover wrong tenant/user/thread, stale, incompatible, invalidated, and WR-01 cases per D-09/D-11. |
| T-54-01-03 | Tampering | current-turn slot replacement | mitigate | Validated explicit current-turn slots override inherited values and record `conflicting_slots` / previous trusted value; unresolved inherited conflicts fail closed; invalidation phrases drop inherited slots per D-09. |
| T-54-01-04 | Repudiation | trace/eval/replay boundary | mitigate | Canonical node writes trace `node == "slot_resolution_gate"` and `slot_resolution_trace` with reason codes; legacy `extract_slots` stays compatibility-only until graph cutover per D-07/D-10. |
| T-54-01-05 | Denial of Service | malformed required-slot state or router exception | mitigate | `route_after_slot_resolution` catches exceptions and returns `clarification_gate`; tests cover required-slot policy mismatch and malformed state per D-12. |
