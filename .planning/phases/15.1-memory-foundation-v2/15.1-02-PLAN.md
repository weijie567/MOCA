<architecture_alignment>
## Architecture Alignment

Canonical owner packages:
- `src/tools` owns tool call/result contracts and manager invocation boundary.
- `src/conversation` owns persistence of conversation-linked tool calls and results.
- `src/agent/nodes/investigate.py` owns state integration for current tool loop results.

Old-path quarantine/deletion strategy:
- Preserve `ToolResultV2.data` as normalized adapter output for business logic, but do not treat it as prompt-safe.
- Replace `state["tool_results"]` full `ToolResultV2.model_dump()` entries with `ToolResultPromptSummary`-shaped projections.
- Keep existing `business_fact_refs` and `policy_evidence_refs` contracts unchanged.

Forbidden new imports/references:
- Tool storage must not import policy KB internals as authority.
- Tool storage must not write approval/action authority object bodies.
- No raw upstream payload blob table is introduced in this phase; `raw_result_ref` and `raw_result_hash` are nullable references only.

Boundary tests required:
- Large nested `ToolResultV2.data` fixture does not appear in AgentState projection.
- Tool result persistence stores normalized JSON separately from prompt summary.
- Existing tool contract tests remain green.

Phase non-overlap:
- Phase 13 owns approval/snapshot authority and must not be copied into tool storage.
- Phase 14 owns demo action draft creation and wording; this plan only stores safe refs/summaries.
- Phase 15 owns replay event append/projection/redaction; this plan may store replay refs but not replay payloads.
- Phase 15.1 owns tool call/result layering for memory foundation.
- Phase 16 owns long-term/case memory and retrieval.
- Phase 17 owns external execution/outbox/reconciliation/compensation.
</architecture_alignment>
