## Resolved Findings

### CR-01: Conversation Context Is Not User-Scoped

**Status:** Resolved.

**Evidence:** `ConversationRepository.get_thread()` now requires `tenant_id + user_id + thread_id`, and message, summary, and tool-result reads resolve the scoped `conversation_thread_id` before reading child records. `ConversationService.load_prompt_context()` now requires and passes `user_id`; both recommendation and risk nodes pass `state["user_id"]`. The model and migration now use `uq_conversation_threads_active_tenant_user_thread`.

### WR-01: Successful Chat Can Silently Lose Final Conversation Memory

**Status:** Resolved.

**Evidence:** The completed chat persistence block now returns `success=False` with an `INTERNAL_ERROR` if final persistence or commit fails, after rollback and exception logging.

### WR-02: Thread Summary Uses Stored Tool `summary` Before Prompt-Safe `prompt_summary`

**Status:** Resolved.

**Evidence:** `_safe_tool_summary()` now tries `prompt_summary` before `summary`, and `tests/memory/test_thread_summary.py` covers a stored unsafe `summary` that must not appear in the rolling summary.

### WR-03: Concurrent Appends Can Allocate Duplicate Message Indexes

**Status:** Resolved.

**Evidence:** `append_message()` now locks the scoped `conversation_threads` row with `SELECT ... FOR UPDATE` before computing `max(message_index) + 1`, and `_next_message_index()` is scoped by `conversation_thread_id`.

### IN-01: Phase Boundary Test Has Self-Fulfilling Assertions

**Status:** Resolved.

**Evidence:** `test_phase_16_and_phase_17_artifacts_are_not_created()` no longer injects forbidden table names into its own assertion set. It checks actual SQLAlchemy metadata and relevant migration source.
