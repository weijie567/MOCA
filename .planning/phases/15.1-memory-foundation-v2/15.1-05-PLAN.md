<architecture_alignment>
## Architecture Alignment

Canonical owner package: `src/agent/context` owns prompt assembly, prompt projectors, and token budgeting. Individual graph nodes own task-specific LLM calls but must request assembled/projected prompt blocks.

Old-path quarantine/deletion strategy:
- Keep existing node behavior and schemas, but replace local raw dict/list interpolation with explicit projectors.
- Existing helper summaries in `generate_recommendation.py` can move to or delegate to `src/agent/context/projectors.py`.
- Live LLM prompt nodes that need current-run context must call `ContextAssembler.assemble()` and consume `PromptAssembly`; direct projector-only assembly is not enough.
- Do not store raw assembled prompts by default.

Forbidden new imports/references:
- ContextAssembler must not import repositories directly in this phase; it accepts already loaded working state, summaries, recent messages, policy snippets, and tool summaries.
- ContextAssembler must not include `ToolResultV2.data`, approval/action authority bodies, trace/debug blobs, raw prompt text, or full policy documents.
- No long-term/case memory retrieval.

Boundary tests required:
- Large nested tool/business fixtures do not appear in assembled prompt.
- Token budget truncates old messages and verbose tool summaries before protected blocks.
- Prompt nodes contain no direct `f"...{dict_obj}..."` interpolation for unprojected state structures.

Phase non-overlap:
- Phase 13 owns approval/snapshot authority; ContextAssembler must not include authority bodies.
- Phase 14 owns action draft/demo outcome authority; ContextAssembler may include only safe action/draft summaries.
- Phase 15 owns replay event projection and redaction; ContextAssembler consumes safe refs/summaries only.
- Phase 15.1 owns prompt assembly and token budgeting.
- Phase 16 owns long-term/case memory and retrieval.
- Phase 17 owns external execution/outbox/reconciliation/compensation.
</architecture_alignment>
