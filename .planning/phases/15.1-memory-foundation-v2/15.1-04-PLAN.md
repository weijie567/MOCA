<architecture_alignment>
## Architecture Alignment

Canonical owner packages:
- `src/memory/thread_summary.py` owns thread rolling summary derivation.
- `src/conversation` owns persistence access to `conversation_messages`, `tool_results`, and `summaries`.
- `src/memory/service.py` remains owner of Phase 12 `session_memories` slot continuity.

Old-path quarantine/deletion strategy:
- Do not replace or rename `session_memories`.
- Do not use `session_summary` as the source range backed thread rolling summary.
- Do not wire long-term/case memory retrieval.

Forbidden new imports/references:
- Thread summary service must not import knowledge service as authority for policy conclusions.
- Thread summary service must not import approval/action services to copy authority objects.
- No vector search, embeddings, tombstone matching, or case precedent search.

Boundary tests required:
- Summary source ranges include start/end message IDs.
- Raw tool payload fixture values are excluded.
- Existing Phase 12 session memory tests still pass.

Phase non-overlap:
- Phase 13 owns approval/snapshot authority and must not be summarized as durable authority.
- Phase 14 owns demo action draft facts; summaries may reference safe conversation text only.
- Phase 15 owns replay redaction and event timeline; summaries must not reuse replay raw payloads.
- Phase 15.1 owns thread rolling summaries for prompt continuity.
- Phase 16 owns long-term/case memory, tombstones, review workflow, and retrieval.
- Phase 17 owns external execution/outbox/reconciliation/compensation.
</architecture_alignment>
