<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Reviewer/admin actor -> graph resume | Reviewer identity is trusted only for approval resume and action-draft permission checks. |
| Original run requester -> terminal memory/CWC finalizer | Requester identity owns assistant-message, thread-summary, session memory, and CWC terminal writes. |
| Approval resume final state -> terminal finalizer | Only completed states with final response may cross into terminal memory finalization. |
| Approval retry metadata -> canonical graph route | Historical persisted retry metadata cannot revive active legacy graph vocabulary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-59-02-01 | Spoofing | `_resume_graph_after_decision(...)` finalizer identity | mitigate | Fetch `User` by `run.user_id` and pass `user=requester`; never pass `actor_user` to finalizer. |
| T-59-02-02 | Tampering | approval resume final state | mitigate | Call finalizer only after durable run status and post-approval trace append; use shared duplicate guard for finalizer trace. |
| T-59-02-03 | Elevation of privilege | action-draft reconciliation | mitigate | Leave `_reconcile_approved_action_draft(...)` existing-draft guard and approved-only permission behavior unchanged. |
| T-59-02-04 | Information disclosure | interrupted/error resume branches | mitigate | Do not write assistant-summary/session-memory/CWC terminal surfaces for interrupted or error states. |
| T-59-02-05 | Tampering | canonical graph vocabulary | mitigate | Keep `risk_gate` canonical route authority and do not add active `assess_risk_and_approval` aliases. |
