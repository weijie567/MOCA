<interfaces>
Catalog declaration contract to create:

```python
@dataclass(frozen=True)
class _ToolDeclaration:
    name: str
    kind: Literal["read", "retrieval", "write"]
    input_schema: dict[str, Any]
    output_schema: dict[str, Any]
    ...
```

Descriptor pass-through must become:

```python
output_schema=declaration.output_schema
```

Concrete output-schema stance:
- `get_order`: strict object with `order_no`, `merchant_id`, `status`, `amount`, `currency`, `buyer_name`, `item_name`, nullable `paid_at`, nullable `delivered_at`, strict nested `relation_hints`.
- `get_refund_case`: strict object with `refund_case_no`, `merchant_id`, `status`, `reason_code`, `reason_text`, `requested_amount`, nullable `approved_amount`.
- `get_ticket`: strict object with `ticket_no`, `merchant_id`, `status`, `channel`, `summary`.
- `get_logistics`, `get_merchant_risk`, `search_sop`: strict empty-object no-data schema: `{"type": "object", "properties": {}, "required": [], "additionalProperties": False}`.
- `search_policy`: strict object with `retrieval_status` enum `strong_evidence|partial_evidence|no_evidence|error`, `best_score`, `threshold`, nullable `summary`.
- `search_case_memory`: strict object with required `items` array; each item has `case_memory_id`, `excerpt`, nullable `applicability`, nullable `outcome`, nullable `caveats`, numeric `score`, `policy_refs` object array, and `source_refs` object array.
</interfaces>
