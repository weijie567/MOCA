<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Executor -> ToolRuntime | Fake and real executors can return malformed `ToolResultV2.data`; runtime must fail closed. |
| Runtime failure -> projection/outcome | Invalid data must be replaced by safe `invalid_response` before projection and outcome serialization. |
| ToolResult envelope -> high-blast consumers | Business, conversation, agent, platform, and memory consumers depend on stable envelope/projection surfaces. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-08 | Tampering | `ToolRuntime.invoke` output gate | mitigate | Fake-executor tests prove invalid `data` maps to `invalid_response` instead of passing through. |
| T-38-09 | Information Disclosure | `_fail(...)` / projection JSON | mitigate | Raw sentinel invalid data must be absent from `outcome.model_dump_json()` and projected surfaces. |
| T-38-10 | Elevation of Privilege | `ToolResultV2` envelope refs | mitigate | Exact `ToolResultV2.model_fields` guard and high-blast tests ensure authority fields are not moved into data. |
| T-38-11 | Denial of Service | DB-backed final suite | accept | Local PostgreSQL availability is environmental; record blocker with reproduction and keep non-DB gates separate. |
</threat_model>
