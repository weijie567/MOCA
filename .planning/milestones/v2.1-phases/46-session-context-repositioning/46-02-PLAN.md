| session context source modules -> authority DTOs | Session hints can enter prompt context but must not construct evidence, business fact, approval, action, CWC, or replay authority. |
| planner-facing tools -> reviewed memory | `search_case_memory` must remain reviewed case memory and not legacy session-derived precedent. |
| Phase 46 plans -> verification tooling | Test commands must use the project virtual environment through the approved uv entrypoint. |

| T-46-02 | T/E | session context modules | mitigate | Static tests reject `EvidenceRefV1` and approval-evidence authority construction from session runtime modules and session schema class blocks. |
| T-46-03 | T | session hints and business refs | mitigate | Static tests reject `BusinessFactRefV1(` construction/imports from session runtime modules and session schema class blocks. |
| T-46-04 | R/T | `search_case_memory` wiring | mitigate | Static tests assert production executor uses `CaseMemoryService.retrieve_reviewed` and not `LegacySessionPrecedentSearchService`. |
