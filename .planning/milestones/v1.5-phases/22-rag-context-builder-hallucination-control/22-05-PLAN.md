<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| verifier result -> route map | Verifier status is trusted only as typed internal data; route selection remains backend deterministic logic. |
| route map -> LangGraph edge | Conditional edge must fail closed and never allow model-chosen safety outcomes. |
| recommendation state -> action boundary | Non-allow verifier state must prevent action/approval/snapshot creation even on direct node invocation. |
| final response -> user/memory/replay | User-facing responses and ordinary state must not leak verifier/debug/provenance/private internals. |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-22-01 | high | Information Disclosure / Elevation of Privilege | recommendation integration | mitigate/block | Consume only Plan 22-03 validated bundle evidence; invalid tenant/scope evidence cannot support claims or reach action path. |
| T-22-02 | high | Tampering | recommendation integration | mitigate/block | Treat hash/current/stale exclusion statuses as non-support and route non-allow before action boundary. |
| T-22-03 | high | Tampering / Information Disclosure | final responses | mitigate/block | Use final-response-safe citations and safe wording; test leakage sentinels across final output. |
| T-22-04 | high | Spoofing / Tampering | business/action claims in graph state | mitigate/block | Require verifier-supported business and policy dependencies before route allow; model text cannot assert support. |
| T-22-05 | high | Elevation of Privilege | `rag_context/routing.py` and `graph.py` | mitigate/block | Backend route map and conditional edge choose allow/non-allow; unknown states fail closed. |
| T-22-06 | high | Tampering / Elevation of Privilege | `assess_risk_and_approval.py` | mitigate/block | Defensive guard blocks proposed actions, approval requests, action drafts, and snapshots on any non-allow verifier status. |
| T-22-07 | high | Information Disclosure | `final_response.py` and AgentState | mitigate/block | Store/render only redacted status, safe reasons, metrics, and citations; verify no raw prompt/provenance/OCR/debug leakage. |
</threat_model>
