## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| conversation memory -> extract_slots prompt | Prior messages/summaries/tool summaries enter prompt context for reference resolution. |
| session memory -> slot resolution | Trusted PostgreSQL slots may satisfy required slots only when scoped and fresh. |
| memory context -> authority checks | Memory context may inform wording/reference resolution but must not become evidence/business/action/replay authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Tampering/Repudiation | duplicate memory context | transfer | Idempotent writes are implemented in Plans 24-03 to 24-07; this plan consumes scoped context. |
| T-24-02 | Repudiation | terminal continuity | transfer | Finalizer ordering is implemented in Plan 24-06. |
| T-24-03 | Spoofing/Tampering | conversation IDs in config | transfer | Trusted ID injection is implemented in Plan 24-05; this plan loads context using those trusted paths. |
| T-24-04 | Information Disclosure | `load_prompt_context`, session slots | mitigate | Context loads and session slots remain tenant/user/thread scoped and fail closed on wrong scope. |
| T-24-05 | Elevation of Privilege/Tampering | `ContextAssembler`, authority verifier | mitigate | Tests assert memory cannot satisfy policy/business/action/replay authority and raw/private fields are excluded. |
| T-24-06 | Repudiation | non-completed context | mitigate | Prompt context uses committed prior summaries/messages only; non-completed false summaries are blocked by Plan 24-07. |
</threat_model>
