# Phase 24.3 Summary: Memory Write Isolation Policy and Observability MVP

## 目标

把 “memory side effect 不能污染主事务” 从 `/agent-runs` finalizer 的局部实现抽成明确 helper，并补安全的最小 trace metrics。

## 交付

- `src/memory/write_isolation.py`
  - 新增 `run_memory_side_effect_in_isolated_session(...)`。
  - 从 parent `AsyncSession.bind` 创建 child `AsyncSession` 执行 memory side effect。
  - child session 成功 commit，失败 rollback 并向调用方抛出；不会 rollback parent session。

- `src/api/services/agent_run_memory.py`
  - completed-run terminal `memory_write` 改为通过隔离 helper 执行。
  - 新增 `TerminalMemoryWriteExecution`，分离 memory write 业务结果和执行 duration。
  - finalizer trace metrics 新增：
    - `memory_write_duration_ms`
    - `slot_count`
    - `fallback_reason`
    - `pii_decision`
    - `pii_classification`

- `tests/memory/test_write_isolation.py`
  - 新增 child rollback 不影响 parent commit 的隔离回归。

- `tests/test_agent_runs_api.py`
  - 扩展 completed finalizer rollback 回归，验证新增 safe metrics。

## 验证

```bash
uv run pytest tests/memory/test_write_isolation.py tests/test_agent_runs_api.py::test_completed_agent_run_finalizer_memory_write_rollback_does_not_remove_terminal_rows tests/agent/test_memory_write_node.py -q
uv run ruff check src/api/services/agent_run_memory.py src/memory/write_isolation.py tests/memory/test_write_isolation.py tests/test_agent_runs_api.py tests/agent/test_memory_write_node.py
```

结果：通过。

## 边界

- 未改变 `memory_write` 节点自身的 timeout/rollback 行为。
- 未记录 raw final response、raw slots、raw tool data、private/debug/authority body。
- 未改数据库 schema。
