# Phase 24.1 Summary: Session Memory Bundle Naming and Read Model Facade

## 目标

低风险修正命名层：把真正的 session memory 表达为一个 read model bundle，包含 rolling summary、recent messages、tool summaries、slot continuity；保留现有 `SessionMemoryView` 和数据库命名，避免破坏 Phase 24 已完成链路。

## 交付

- `src/memory/schemas.py`
  - 新增 `SessionMemoryBundle`。
  - 新增 `SessionRollingSummaryView`、`SessionRecentMessageView`、`SessionToolSummaryView`。
  - 新增 `SlotContinuityMemoryView = SessionMemoryView` 只读别名，给后续迁移提供更准确术语。

- `src/memory/session_bundle.py`
  - 新增 `SessionMemoryBundleService.load_session_memory_bundle(...)`。
  - Facade 聚合 `ConversationService.load_prompt_context(...)` 的 rolling summary / recent messages / tool prompt summaries，以及 `MemoryService.load_session_memory(...)` 的 slot continuity。
  - Facade 只投影 prompt-safe 字段，不暴露 raw tool result、debug、private reasoning 或 authority body。

- `src/memory/__init__.py`
  - 导出新 bundle schema、子视图、service 和 slot-continuity 别名。

## 回归

- `tests/memory/test_session_memory_bundle.py::test_session_memory_bundle_facade_loads_all_short_term_surfaces`
- `tests/memory/test_session_memory_bundle.py::test_slot_continuity_view_alias_keeps_existing_session_memory_contract`

## 设计边界

- 不改表名、不改已存在 API payload、不改 graph node 名称。
- 旧 `SessionMemoryView` 继续表示 PostgreSQL-backed slot continuity。
- 新 `SessionMemoryBundle` 是 read model facade，不引入新的写入路径。
