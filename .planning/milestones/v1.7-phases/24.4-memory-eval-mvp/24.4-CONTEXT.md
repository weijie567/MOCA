# Phase 24.4: Memory Eval MVP - Context

**Gathered:** 2026-06-21
**Status:** Ready for planning
**Source:** Memory architecture follow-up

<domain>
## Phase Boundary

Phase 24.4 不引入外部 benchmark、不使用 LLM judge，只建立 MOCA 自己的 deterministic memory eval fixtures。目标是把关键 memory 质量门集中固化，避免后续 memory read/write/prompt 改动破坏 recall、expiry、forgetting 和 authority boundary。
</domain>

<decisions>
## Implementation Decisions

### Eval Scenarios

- Same-thread recall：session bundle 能同时读到 prior rolling summary、recent messages、tool summaries 和 slot continuity。
- Stale slot non-leak：过期 slot 不进入 active slots。
- Tombstone non-revival：被 forget/tombstone 的 long-term memory 不能被同内容写入复活。
- Authority contamination negative：memory snippets 不能生成 policy evidence block，也不能把 forbidden authority markers 原样带进 prompt。

### Scope

- 只做 deterministic pytest fixtures。
- 不引入外部 dataset、benchmark runner、LLM-as-judge 或新的服务进程。
- 不改变生产代码，除非测试暴露真实 bug。
</decisions>
