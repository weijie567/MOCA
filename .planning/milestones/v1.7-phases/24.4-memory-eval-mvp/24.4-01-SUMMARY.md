# Phase 24.4 Summary: Memory Eval MVP

## 目标

建立 MOCA 自己的 deterministic memory eval MVP，不引入外部 benchmark、LLM judge 或新服务。

## 交付

- `tests/memory/test_memory_eval_mvp.py`
  - `test_memory_eval_same_thread_bundle_recalls_prompt_safe_surfaces`
    - 验证同线程 bundle 能读到 rolling summary、recent messages、tool summaries 和 slot continuity。
  - `test_memory_eval_stale_session_slot_does_not_leak`
    - 验证过期 slot 不进入 trusted active slots。
  - `test_memory_eval_tombstoned_long_term_memory_does_not_revive`
    - 验证已 tombstone 的 long-term memory 不能通过同内容写入复活。
  - `test_memory_eval_memory_context_cannot_create_policy_evidence_or_authority_prompt_blocks`
    - 验证 memory snippets 不能生成 `policy_refs` block，也不会把 forbidden authority/debug/raw markers 原样带进 prompt。

## 验证

```bash
uv run pytest tests/memory/test_memory_eval_mvp.py tests/agent/test_memory_evidence_boundary.py -q
uv run ruff check tests/memory/test_memory_eval_mvp.py
```

结果：通过。

## 边界

- 未新增外部 eval dataset。
- 未使用 LLM-as-judge。
- 未改生产代码。
