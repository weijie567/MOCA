## Cross-File Review Notes

`TrustedContextFactory` remains the only production authority that can derive wildcard merchant scope, and only for stored `admin` users. Non-admin server overrides cannot widen merchant scope, and the approval resume path no longer injects `server_merchant_scope`.

Business tool call chains project tool context from trusted context, then re-check tenant, persisted user role, active status, and merchant binding before returning order, refund-case, or ticket data. The agent investigation node fails closed when trusted context is missing, so legacy state/config fields cannot silently grant tool permissions or merchant visibility.

Approval list/get/decide/info routes are admin-only at the API gate and at the approval policy layer. Run status, evidence, trace, and replay visibility remain restricted to the run owner or admin, with run event streaming/execution restricted to the owner.
