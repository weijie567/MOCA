<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| ToolCatalog -> ToolPolicyEngine -> ToolViewV1 | Full descriptors contain policy/runtime metadata and cross into prompt-facing planner visibility only through a whitelisted projection. |
| TrustedContext / ToolCallContext -> ToolPolicyEngine.runtime_auth | Trusted identity, permissions, merchant scope, and caller-local fields cross into authorization; LLM/user args cannot widen these fields. |
| ToolRuntime -> domain executor | Runtime checks must complete before executor dispatch; denied calls must not reach business/knowledge/memory/action executors. |
| ToolResultV2.data -> ToolResultProjector | Raw-ish adapter output crosses into graph/prompt/persistence only through normalized and prompt-safe projections. |
| ToolPolicyDecision -> emit_decision_event -> agent_trace_events | Tool policy decisions cross into durable replay audit through Phase 28 minimal event envelope and redaction guards. |
