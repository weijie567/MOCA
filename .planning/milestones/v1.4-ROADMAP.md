## Milestone Summary

v1.4 turns the v1.3 PostgreSQL hybrid retrieval foundation into a production policy-source ingestion foundation. Maintainers can ingest Markdown/plain text, PDF, DOCX, image, and scanned-PDF policy sources through project-owned parser/OCR adapters; chunks retain canonical citation text while durable source-block provenance remains available through a verified tenant/hash-checked maintainer lookup.

The milestone preserves the existing authority boundaries:

- `PolicyChunk.content` remains canonical citation text.
- `PolicyChunk.search_text` remains retrieval-only enrichment.
- `EvidenceRefV1` remains schema-compatible with v1.3 and is not extended with parser/OCR/source-block fields.
- Parser/OCR/source-block metadata stays internal/debug/provenance data and cannot become business fact, memory authority, approval evidence, action authority, or replay truth.

## Delivered Capabilities

- Project-owned parser/OCR DTOs, parser registry routing, source type/extension/signature/size/page/image/zip hazard guards, parser timeout handling, and safe failure codes.
- Markdown/plain-text adapters with deterministic synthetic source-block IDs.
- PDF/DOCX/image/scanned-PDF adapters with page/table/cell/OCR metadata and Tesseract `chi_sim+eng` preflight.
- Durable `DocumentBlock` source blocks, source block refs on chunks, `RagIngestionJob` safe traces, and policy version fingerprints separated from parser trace metadata.
- Block-aware and table-aware chunking that keeps `PolicyChunk.content` faithful to visible citation text and writes title/section/table/source context only into retrieval-only `search_text`.
- Atomic ingestion that parses, OCRs, chunks, and embeds before the short document write transaction replaces committed documents/chunks/blocks.
- Tenant/hash-verified source-block provenance lookup and allowlisted ingestion report projection.
- Boundary regression coverage across evidence refs, API evidence serialization, prompt assembly, memory, approval snapshots, action/replay payloads, Tool System facts, and v1.3 hybrid retrieval semantics.
- Alembic migration/downgrade/reupgrade coverage for Phase 21 structures without regressing Phase 20 hybrid retrieval columns/indexes.
