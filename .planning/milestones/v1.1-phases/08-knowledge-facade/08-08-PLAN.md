# 08-08 PLAN: Gap Closure — WR-01 policy-text regression + WR-02 citation audit + IN-01 exception scope

<objective>
Close three findings confirmed by the fresh Phase 8 code review (08-REVIEW.md, 2026-06-07T08:30), Claude adjudication against real code, and Codex independent cross-verification. Priority order: WR-01 → WR-02 → IN-01.

1. **WR-01 (functional regression, highest):** Phase 8 deleted the recommendation node's access to policy text. Pre-Phase-8 (`b9050db1~1:generate_recommendation.py`) `_summarize_evidence` carried `"text": (item.get("text") or "")[:1600]`; after Phase 8 switched the evidence source to `EvidenceRefV1` (hash-only, no text), the model is asked to produce a policy-grounded recommendation while seeing zero policy substance. Membership validation is member-only by design (D-C1/D-C2) and cannot compensate. Restore bounded policy text via a transient channel that never touches persistence/API/hash/projection.

2. **WR-02 (audit inconsistency bug):** In `generate_recommendation.py:166-188`, a mixed member/non-member citation set drops invalid refs but only sets `recommended_action="citation_invalid"` when ALL refs are dropped. With a surviving ref, `recommended_action` keeps the model's value while `citation_validation` persists the stale pre-drop `is_valid=False`. `_derive_final_status` (trace.py:223-232) keys off `recommended_action`, so the run reports `completed` while the audit record says citations were invalid. Re-validate surviving citations so the persisted record matches the emitted draft.

3. **IN-01 (robustness):** `generate_recommendation.py:203` and `assess_risk_and_approval.py:274` catch `(ValidationError, ValueError, TimeoutError, Exception)`. The tuple is redundant (`Exception` is the base) and swallows programming errors (`KeyError`/`AttributeError`/`TypeError`) as transient. Narrow to the genuinely transient set; let programming errors propagate.

This plan modifies existing source/test files and adds one transient schema + one ephemeral state field. No DB schema migration, no graph topology change, no public contract change (the transient channel is `exclude=True` and never serialized).
</objective>

## Design constraint (verified against real data flow)
Policy text must cross `retrieve_policy_evidence` → `generate_recommendation`, which only communicate via AgentState. These exits MUST NOT carry text:
- `state["retrieved_evidence"] = result.model_dump()` (retrieve_policy_evidence.py:133) → API serialized (agent_runs.py:473-474), trace read (trace.py:201-207).
- `state["evidence_refs"]` (EvidenceRefV1 dicts) → persisted + API `_dedupe_evidence_refs` (agent_runs.py:500).
- `canonical_evidence_projection` (schemas.py:120) → golden-bytes locked (test_evidence_projection.py:80-89).

Decision (user-confirmed): carry transient text in a **dedicated ephemeral AgentState field**, not by reusing `retrieved_evidence`. The transient payload also rides on `KnowledgeSearchResult` via `Field(exclude=True)` so `model_dump()` strips it mechanically (not by hand).

Data-source fact: `PolicyChunk` has `content`, `section`, but NO `title` (src/db/models.py:179-196). Payload fills `text`(=content) and `section`; `title` has no source.

- On no survivor: `recommended_action == "citation_invalid"`, `is_valid == False`, `final_status == insufficient_evidence` (no regression).
- The two named except sites catch only `(ValidationError, ValueError, TimeoutError)`; programming errors propagate; expected errors still retry+fallback.
- `test_evidence_projection.py` golden bytes unchanged. No regressions in the full suite.
