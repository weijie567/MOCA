# 08-07 PLAN: Gap Closure — allow_partial_evidence + effective-time pre-filter

<objective>
Close the two blocking gaps found by Phase 8 verification (08-VERIFICATION.md):

1. **Gap 1:** `PolicyKnowledgeService.search()` ignores `request.allow_partial_evidence`. When the flag is `False` and the adapter returns `partial_evidence`, the service must return `no_evidence` with empty `evidence_refs`.
2. **Gap 2:** `PolicyChunkRepository.search_similar()` applies SQL `LIMIT` before effective-date filtering. Future-dated high-similarity chunks can crowd out valid current evidence. Push `effective_date` into the SQL WHERE clause.

Gap 3 (tenant-over-global) is NOT fixed here — CONTEXT.md D-D1 explicitly defers it to a later policy-scope phase. The VERIFICATION.md flagged the missing roadmap owner; this plan records the disposition but does not change scope.

This plan modifies existing source and test files only. No new modules, no schema migration, no graph changes.
</objective>
