<architecture_alignment>
## Architecture Alignment

API shape:
- Add `GET /api/v1/agent-runs/{run_id}/replay` beside the existing `GET /api/v1/agent-runs/{run_id}/trace`.
- Return `ApiResponse(success=True, data={...}, trace_id=...)`.
- Response data must include `schema_version="replay_response.v3"`, `run_id`, `thread_id`, `final_status`, and `timeline`.
- Every timeline item must validate as `ReplayEventV3`.

Read-switch/fallback:
- `/replay` calls `ReplayService.get_replay()` and reads `agent_trace_events` first.
- Legacy/minimal rows are projected to V3 with provenance.
- `/trace` remains on `TraceRepository.build_timeline()` and remains the rollback/debug fallback.
- Do not remove `_safe_draft_outcome()` or `_safe_proposed_action()` from `/trace` behavior.

Access control:
- Reuse `/trace` run lookup semantics: `repo.get_run(run_uuid, user.tenant_id)` gives cross-tenant 404.
- Same-tenant non-owner non-supervisor returns 403.
- Supervisor roles remain `supervisor`, `admin`, `approval_manager`, and `manager`.
</architecture_alignment>
