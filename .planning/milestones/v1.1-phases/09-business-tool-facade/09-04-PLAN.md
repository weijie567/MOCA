Create `BusinessToolService` with constructor `__init__(self, registry: ToolRegistry, session: AsyncSession)` and concrete classmethod factory `BusinessToolService.with_default_registry(session) -> BusinessToolService`. The factory assembles a `ToolRegistry` populated with the real Phase 09-03 `get_order_adapter`, `get_refund_case_adapter`, and `get_ticket_adapter` functions and their Plan 09-02 descriptors. This plan owns the registry↔adapter composition root; callers must not hand-assemble the live read registry. Implement `async def invoke_tool(self, name: str, args: dict[str, Any], ctx: ToolCallContext) -> ToolResultV2`; it calls `registry.invoke(name, args, attempt_ctx, self.session)`. `ToolCallContext` must not contain `AsyncSession`, `session`, `db`, or any `Any`-typed DB handle; only its existing nullable `session_id` is allowed.

Before calling registry, deny empty/None `ctx.merchant_scope` with `status="permission_denied"`, `ToolError(code="EMPTY_MERCHANT_SCOPE", safe_message="Merchant scope is required", retryable=False, source="caller")`, `data=None`, empty refs, `latency_ms=0`, `audit_ref=None`. Add a deterministic `_merchant_scope_allows(merchant_scope, *, merchant_id=None, category=None, risk_level=None) -> bool` helper implementing §8.0 all-provided-dimensions matching, explicit `"*"` wildcard, and deny-before-allow semantics. The descriptor permission-token check (`required_permission in ctx.permissions`) is the concrete enforceable authorization gate per §12.5. Apply the scope helper when real resource dimensions are available; never fabricate or require `args["merchant_id"]` for order/refund/ticket. These three reads expose only order/refund/ticket identifiers, so resource merchant enforcement remains at the raw-layer `merchant_can_access` seam; test the helper's no-widening deny logic directly when the adapter input cannot express the dimension. Unknown category must deny when a provided resource category does not match the trusted category dimension. If `ctx.attempt > ctx.max_attempts`, return a safe exhausted result without invoking registry.

Otherwise loop attempts from `ctx.attempt` to `ctx.max_attempts`, using `ctx.model_copy(update={"attempt": attempt})`; call `registry.invoke(name, args, attempt_ctx, self.session)`. Return immediately on non-retryable result or success. Retry only `result.retryable is True`; after the final attempt return the final typed result. Preserve the original `tool_call_id` on every copied retry context. Do not add `max_iterations` or graph routing.
