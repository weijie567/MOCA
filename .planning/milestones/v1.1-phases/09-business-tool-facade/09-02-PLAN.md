  <action>
Implement `async def invoke(self, name: str, input_data: dict[str, Any], ctx: ToolCallContext, session: AsyncSession) -> ToolResultV2` in this exact order. Add an inline `SCF-8` comment at the signature documenting that the explicit fourth `session` argument is the non-context DB runtime dependency while the §12.6 logical resolve→gate→validate→adapt contract remains unchanged:

1. Resolve descriptor/registered tool; unknown returns `status="not_found"`.
2. If `descriptor.kind == "write"`, return `status="permission_denied"` and `ToolError(code="WRITE_TOOL_BLOCKED", safe_message="Write tools cannot execute through BusinessToolService", retryable=False, source="caller")` before adapter access.
3. Require `ctx.caller_node in descriptor.caller_allowlist`; otherwise permission_denied/source caller.
4. Require `descriptor.required_permission in ctx.permissions`; otherwise permission_denied/source caller.
5. Validate `input_data` by selecting the descriptor-associated Pydantic input model and calling `model_validate`; Pydantic failure returns invalid_request/source caller. The descriptor itself still stores only `input_schema: dict[str, Any]`.
6. For declared-only/register-but-unavailable tools with no executable Phase 9 adapter, return `status="unavailable"`, `data=None`, without execution.
7. In `try/except`, await the injected adapter as `await adapter(input_model, ctx, session)`. Convert any unexpected exception to a safe `ToolResultV2(status="error"` or `"unavailable", data=None, ...)`; never expose exception text, raw payload, or partial adapter data.
8. Validate `result.data` against the JSON-schema-shaped `descriptor.output_schema` dict. Validation failure returns a newly constructed `ToolResultV2(status="invalid_response", data=None, safe summary/error, empty refs, ...)`; never return or summarize the invalid raw data. Return the adapter result only after validation passes.

Every registry-created result must use safe summary/source strings, `data=None`, empty refs, `retryable=False` unless explicitly applicable, required `latency_ms=0`, and `audit_ref=None` (SCF-4). Do not implement loop/retry control, policy evidence extraction, or execute write adapters.
  </action>
