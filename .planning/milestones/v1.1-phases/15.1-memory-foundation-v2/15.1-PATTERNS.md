## Data Flow Target

1. API/graph receives user turn.
2. Conversation service appends user message for `(tenant_id, thread_id, run_id)`.
3. Tool manager/investigate writes `tool_calls` and `tool_results`; state receives only refs, summaries, statuses, business refs, and evidence refs.
4. Final response appends assistant message.
5. Summary service derives or updates `thread_rolling` summary from source message/tool result ranges.
6. WorkingStateV1 projects current `AgentState` into prompt-safe state.
7. ContextAssembler combines protected blocks and drops/truncates non-protected blocks by token budget.
8. Replay/audit IDs remain correlated but replay redaction remains unchanged.
