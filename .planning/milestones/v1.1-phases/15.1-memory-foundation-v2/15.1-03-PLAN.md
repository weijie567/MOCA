## Architecture Alignment

Canonical owner package: `src/agent/working_state.py` owns the prompt-safe projection. `src/agent/state.py` remains the LangGraph state contract and checkpoint shape.

Old-path quarantine/deletion strategy:
- Do not add a `working_memory` table.
- Do not remove existing `AgentState` fields in this plan.
- New prompt assembly code must consume `WorkingStateV1` instead of raw `AgentState` where working state is needed.

Forbidden new imports/references:
- `WorkingStateV1` must not import database repositories.
- `WorkingStateV1` must not include raw `ToolResultV2.data`, full `business_context`, `llm_outputs`, `trace_steps`, approval authority bodies, or action authority bodies.
- It must not emit policy full text; policy refs/snippets remain ContextAssembler-owned.

Boundary tests required:
- Allowlisted fields survive projection.
- Denylisted raw/authority/debug fields are absent.
- Large nested tool result values do not appear in JSON serialization of `WorkingStateV1`.

Phase non-overlap:
- Phase 13 owns approval/snapshot authority; WorkingStateV1 may expose only safe refs/status summaries.
- Phase 14 owns action draft/demo outcome authority; WorkingStateV1 must not expose action payload bodies.
- Phase 15 owns replay and trace event facts; WorkingStateV1 must not expose replay raw payloads or trace/debug blobs.
- Phase 15.1 owns prompt-safe current-run projection.
- Phase 16 owns long-term/case memory and retrieval.
- Phase 17 owns external execution/outbox/reconciliation/compensation.
</architecture_alignment>
