## Decisions Made

- Kept ContextAssembler pure: it accepts already loaded working state, summaries, recent messages, policy snippets, and tool summaries; node code performs optional `ConversationService.load_prompt_context()` reads.
- Kept slot extraction context-light: it uses current user text plus projected candidate hints and does not synthesize thread/tool context when none is required.
- Kept raw tool result refs as opaque refs in tool summaries while excluding `ToolResultV2.data`, authority bodies, trace/debug blobs, and raw dict/list reprs from prompts.
