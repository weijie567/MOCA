<architecture_alignment>
## Architecture Alignment

Canonical owner packages:
- `src/conversation` owns conversation/tool/summary rows and safe correlation refs.
- `src/replay` owns replay event append/projection/redaction.
- `src/repositories/audit_repo.py` owns durable audit log append where existing audit rows are needed.
- `src/agent/context` owns prompt assembly and token budgeting.

Old-path quarantine/deletion strategy:
- Keep `/trace` and `TraceRepository.build_timeline` as fallback surfaces if still present.
- Do not make replay rows the conversation log.
- Do not make conversation rows the audit/replay event stream.

Forbidden new imports/references:
- No direct import from `src/conversation` into policy/approval/action services for authority decisions.
- No code path treats `summaries.case_id` or `conversation_threads.case_id` as retrieval predicate.
- No external execution/outbox/reconciliation code.

Boundary tests required:
- A chat/tool/recommendation flow can correlate user message, assistant message, tool call, tool result, run ID, trace ID, operation/tool call ID, and replay/audit refs.
- Replay redaction tests still reject forbidden raw keys.
- Session memory and thread summary regressions stay green.

Phase non-overlap:
- Phase 13 owns approval/snapshot authority and remains the source for approval correctness.
- Phase 14 owns action draft/demo outcome authority and remains the source for draft correctness.
- Phase 15 owns ReplayEventV3 append/projection/redaction and remains the source for replay correctness.
- Phase 15.1 owns cross-layer memory foundation ID correlation and prompt-safe context boundaries.
- Phase 16 owns long-term/case memory, tombstones, review workflow, and retrieval.
- Phase 17 owns external execution/outbox/reconciliation/compensation.
</architecture_alignment>
