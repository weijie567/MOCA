<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user text -> intent classifier | Untrusted ordinary chat may include approval-looking text or action language. |
| LLM structured output -> AgentState | Model output is untrusted and must be schema-validated plus adapter-mapped. |
| classifier state -> downstream routers | Later routers consume only allowed, typed fields from this plan. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Spoofing / Elevation of Privilege | `classify_intent` | mitigate | Exclude `approval_decision` from `IntentResultV3`; tests assert ordinary chat cannot write `approval_result`, trusted versions, or resume commands. |
| T-11-02 | Tampering | `IntentResultV3` | mitigate | Use `ConfigDict(extra="forbid")` and `intent_result_to_state` field-by-field adapter. |
| T-11-03 | Tampering / Information Disclosure | slot fields | transfer | This plan marks `candidate_slots` as hints only; Plan 11-03 implements deterministic slot completeness. |
| T-11-04 | Elevation of Privilege | confidence fields | mitigate | Store model confidence in `intent_confidence`; calibrated confidence only in eval metadata; no confidence-only action routing is implemented here. |
| T-11-05 | Repudiation | manifest/eval metadata | transfer | This plan writes classifier/calibration metadata; Plan 11-05 implements manifest/hash stale-coverage failure. |
</threat_model>
