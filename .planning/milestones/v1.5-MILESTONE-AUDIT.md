## Tech Debt / Non-Blocking Items

1. **Defensive business fact ref status filtering**
   - Integration checker warning: `generate_recommendation` copies refs from flattened `tool_results` without checking success status.
   - Current upstream paths only promote useful refs on success, and verifier still requires business authority, so this is hardening debt rather than a confirmed bypass.
   - Affected requirements: `CLM-03`, `CLM-05`, `BND-03`, `RTE-02`, `EVAL-02`.

2. **Production-verifier eval coverage depth**
   - The golden eval has 24 cases and 5 production-verifier cases, including unsupported claim text, hash mismatch, latest invalid, freshness invalid, and OCR low-confidence.
   - Many authority-boundary cases still use deterministic adapter paths. This is acceptable for v1.5's deterministic local gate but should be expanded if the eval becomes a stronger E2E oracle.

3. **Eval script header drift**
   - `scripts/eval_phase22_hallucination.py` has a header comment that still describes an earlier future-adapter state.
   - Functional wiring is present and verified; this is documentation drift.

4. **Validation artifact wording drift**
   - `22-VALIDATION.md` frontmatter is compliant, but its task table still says `pending`.
   - Final verification artifacts supersede the table, but future audits may benefit from refreshing it.

5. **Deferred 17-prep AgentState cleanup**
   - `.planning/todos/pending/2026-06-17-constrain-agentstate-memory-expansion.md` remains pending as `17-prep: AgentState Surface Contracts + Authority Isolation`.
