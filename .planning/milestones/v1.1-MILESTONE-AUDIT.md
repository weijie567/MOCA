## KNOW-02 Disposition

Current implementation remains tenant-scoped only. This is intentional and now explicitly owned:

- Owner: post-Phase 17 `Policy Scope`.
- Rationale: current policy tables and retrieval queries are tenant-scoped; global/default fallback requires schema and query semantics that are outside v1.1 MVP.
- Dependency: explicit global/default policy scope schema plus retrieval merge semantics.
- Acceptance gate: schema/query migration tests prove tenant policy wins over global/default fallback when both match, fallback applies only when tenant policy is absent, and evidence identity, citation validation, content lookup, and rollback behavior remain safe.

This is no longer a readiness blocker because it has owner, rationale, dependency, and acceptance gate.
