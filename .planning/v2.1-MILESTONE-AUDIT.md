### Confirmed Gap: Approval Resume Bypasses Terminal Memory Finalizer

Affected requirements: MEM-01, MEM-02, MEM-03, CAGM-08, CAGM-09.

Evidence:

- Normal run completion calls `finalize_completed_agent_run_memory(...)` from `src/api/routers/agent_runs.py:393` and again on another completion path in the same router.
- `finalize_completed_agent_run_memory(...)` in `src/api/services/agent_run_memory.py:53` appends or reuses the assistant message, persists the thread summary, runs terminal `memory_write`, and writes Case Working Context finalization trace steps for completed runs.
- Approval resume completion in `src/api/routers/approvals.py:283` through `src/api/routers/approvals.py:349` resumes the graph, reconciles action draft state, computes final status, updates `AgentRun`, and appends post-interrupt trace steps. This path has no import or call to `finalize_completed_agent_run_memory`.
- `rg` confirms `finalize_completed_agent_run_memory` is only imported/called from `agent_runs.py`, not from `approvals.py`.

Impact:

An approval-gated turn can complete through the approval resume endpoint while skipping the same terminal assistant-message/thread-summary/memory/CWC finalization used by normal `agent-runs` completion. The run status can look completed while contextual memory surfaces remain stale for that lifecycle path.

Recommended closure:

- Add a small closure phase or milestone-gap phase that wires `finalize_completed_agent_run_memory(...)` into the approval resume terminal-completed path with idempotency-compatible behavior.
- Add regression coverage proving approved action resume completion persists the assistant message, thread summary, terminal memory write trace, and CWC finalizer trace steps, using the MOCA-approved test entrypoint (`UV_CACHE_DIR=/tmp/uv-cache uv run ...`).
- Decide whether interrupted-again resume paths should explicitly skip finalization with a trace reason, or only completed paths should call the finalizer.
