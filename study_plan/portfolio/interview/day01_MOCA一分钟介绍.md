# Day 1 · MOCA 一分钟介绍稿

## 用途

面试开场用 60 秒回答：“你这个 MOCA 项目是做什么的？”

## 版本 0 草稿

MOCA 是一个面向商家运营场景的 Merchant Operations Copilot Agent，主要处理退款、争议和补偿类问题。它不是泛聊天机器人，而是一个带明确工作流边界的 Agent 系统：先识别用户意图，再读取订单、退款、工单和政策证据，生成带引用的建议；如果涉及高风险补偿或退款，就进入审批流程，只生成 draft，不直接执行真实外部动作。

这个项目里我最想展示的是三点：第一，RAG 不只是检索，而是要有证据契约和 citation validation；第二，高风险动作必须有人审、snapshot 和 hash 绑定，防止模型绕过业务边界；第三，trace、replay 和 eval 让系统可以被复盘和测试，而不是只看一次 demo。
