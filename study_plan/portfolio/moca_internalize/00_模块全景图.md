# Day 1 · MOCA 模块全景图

> 这是手画图的承载文件。图本身不要让 AI 代画；明天先在纸上或 draw.io 画，再把截图、链接或 Mermaid 草稿放到这里。

## 用途

- 面试开场时 1-2 分钟讲清 MOCA 是什么。
- 给后续 D2-D5 的 Agent 编排、审批状态机、RAG 证据、记忆与可观测复盘提供总地图。
- 防止只记住零散模块，讲不出主链路。

## 核心内容

明天手画时至少包含这些模块：

1. 用户入口：React / API / chat or SSE。
2. 编排层：LangGraph graph、intent、slot、investigate、recommendation、approval、final response。
3. 工具与知识：business read tools、policy/RAG、memory read。
4. 风险与审批：risk rules、approval request、approval decision、draft-only action。
5. 可观测与评测：trace / replay / eval reports。
6. 数据层：PostgreSQL、pgvector、Redis、policy chunks、agent run/audit tables。

## 验收标准

- 能对着图讲 8 分钟，不需要打开源码。
- 每条箭头都能说清“输入是什么、输出是什么、失败时怎么办”。
- 至少标出 3 个边界：模型不能直接写数据库、模型不能直接执行高风险动作、没有证据不能假装有证据。
