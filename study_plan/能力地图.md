# 能力地图 · AI Builder / 技术型 PM

> 主方向：**AI Builder / 技术型 PM**（绕开"3年PM经验"死门槛，把技术底子+MOCA 变成核心资产）
> 配比：45% MOCA 内化 · 30% Agent 工程最小线 · 25% 产品表达
> 30 天计划里每一天都挂在下面 16 项能力的某几项上。

---

## 锁定的方向判断（地基）

| 维度 | 结论 |
|---|---|
| 主方向 | AI Builder / 技术型 PM |
| 写代码 | 愿意，但高成本耗时，目标=生产最小线，不追求资深工程师 |
| 市场 | 中英双投，技术栈 OpenAI/Anthropic 为主 + Qwen/豆包兼容补充 |
| 状态 | **已在求职中** → 边战边练，作品集尽早能用 |
| MOCA | **大部分说不清** + 停在 Phase 15（14+15 交 Codex）→ 内化是全程主轴 |
| 最大风险 | 带着"讲不清的 MOCA"去面试，比没项目更危险 |

### 成功率判断（务实，非鸡汤）
- **纯 AI PM 岗**：进面率低，被"3年经验"硬卡，30天补不出 title。只机会型补投。
- **Agent 工程岗（1年经验档）**：能投能约面，但**技术面是生死线**，取决于 MOCA 内化深度。
- **AI Builder / 技术型 PM（最优解）**：绕开经验门槛，认 GitHub、认能跑的东西、认 Builder 心态。MOCA + 双AI协作 + 能讲清，是你的差异化。
