## 简历项目描述模板（D27 产出，这里给骨架）

```
MOCA — 面向电商/本地生活商家运营的 AI Agent（个人项目）
技术栈：FastAPI · LangGraph · OpenAI · pgvector · Redis · PostgreSQL · Docker

· 设计并实现带证据契约的 RAG 检索，每条业务建议可溯源到政策原文 chunk，降低幻觉风险
· 设计高风险动作（退款/补偿）审批状态机，审批结果绑定 action 快照 hash，支持中断/恢复，
  保证敏感操作必须经人审且不可被篡改
· 建立 offline 评测体系（golden/红队/异常三套集），可量化检索召回、引用覆盖、策略合规
· 采用 Claude 设计把关 + Codex 执行的双 AI 协作工作流，在保证架构契约一致性的同时放大开发产出

* bullet 要点：每条 = 动作 + 怎么做 + 解决什么问题/什么结果。面试时每条都能展开 5 分钟。
```
